# 通用地形纹理规则

用户定稿的一至五层主纹理统一纳入公共流水，规则名为 `classic-natural`；第四层为用户圈选的 4A 棕岩，第五层为 5A 浅灰岩。选材定义统一在 `src/terrain/materials.rs`，报告修订号为 `five-layer-2026-10-29`。自然纹理噪声、岸线和混合按下述当前规则处理，不提供旧地图或历史配色的执行入口。

坡面、层界、岸线及交汇处按[地形交接规范](terrain_transitions.md)先定联合几何与预期通行，再整理表面。下文的距岸／距崖带宽是当前刷材质实现，不能替代岸坡、坡肩或完整可通行宽度；普通混合、第二混合及存在的悬崖 UV 须一并核对。AXAI／NKL／SMAI 参考借鉴连续接合方法，当前五层选材不变；纹理更新保护几何和导航，也会保留其中尚未修复的问题。

## 构建与成品更新

- 新蓝图 `build`：在 `map` 阶段完成高度、位图、对象、脚本及资源配套后，自动执行公共纹理后处理。后续 `verify`、`accept`、`dist` 使用同一成品。完整原生来源编辑保护本轮无关的合法纹理，仍执行当前全部严格门禁；需要更新选材时使用下一条入口。
- `polish-textures <源ZIP> --map <id> --bump`：对现有成品执行相同函数，保留已经完成的斜坡优化和 WorldBuilder 定稿内容。
- `TEXTURE_PROFILE` 只接受 `classic-natural`，缺省相同；`legacy` 和其他值在构建、原生编辑入口均明确拒绝。显式 `polish-textures` 应用同一当前规则。
- 新蓝图构建由各图自己的蓝图和布局生成地形；已启用坐标流水的成品沿用各自冻结原生制作源。已有成品只改纹理时使用后一个入口，避免从旧蓝图重建地形。

## 公共纹理清理与数量上限

2026-10-29，按用户要求纳入公共制作规范：**构建器必须清除全部未使用的地形纹理，最终地形纹理不得超过 49 种**。未超过上限时也必须清理，不以删到 49 项为止。

- 使用情况同时检查主贴图、普通混合、第二混合平面与悬崖 UV；仅被混合或悬崖引用的纹理仍属已使用。
- 清理后统一重映射保留纹理及混合引用，同步原生材质表、`WorldInfo` 加载清单、XML `WorldDict` 和 `TerrainTextureAtlas`，删除 XML 中的多余登记。
- 保留逐格实际材质、子贴片相位、混合效果、高度、全部导航/建造位图、对象与脚本。不得通过改画地形或删除资源声明规避超限。
- 清理后实际使用纹理仍超过 49 种时，构建与发布必须失败；发布包、安装和采用制作源均执行 49 项上限检查。64 项图集存储容量只属于内部处理边界，不是可发布数量。

新蓝图及显式地形／纹理整理共用 `terrain_package::compact`。完整原生来源、原样重建和重新封装同样满足当前纹理、资源与玩法要求；原生字节未变不构成豁免。需要整理时从当前受控完整源执行相应编辑，通过严格验收后再采用来源，不用历史模式或缺失布局绕过检查。

## 当前五层主纹理

高度层取当前地图的 `LAYER_M`，缺省使用 `TERRAIN.levels`，排序去重后从低到高对应以下五层，不硬编码地图坐标。显式五层配置按最近标高分层；仅声明可玩台地时，高于最高台地且高于 `WATER_Z + PEAK_IMPASSABLE` 的实际山峰使用第五层材质。不会把配置中本来就很高的第四层台地误刷成第五层，也不会改变高度或通行规则。

| 地表 | 材质与分配 |
|---|---|
| 最低陆地层 | `Grass_NewYork01`，少量 `Grass_CapeCod05` |
| 第二层 | `Grass_MtRush04`，少量 `Grass_Geneva01` |
| 第三层 | `Grass_CapeCod05`，少量 `Dirt_Iceland05` |
| 第四层 | `Rock_Yucatan03`，棕色山岩；不另铺草地或裸土变体 |
| 第五层及更高山峰 | `Rock_Iceland02`，浅灰山岩；不另铺草地或裸土变体 |
| 层界 | `Rock_Yucatan01`，邻近碎石或土壤衔接 |
| 岸线 | `Sand_Hawaii02`，约 3–5 格宽，随后局部土壤衔接 |
| 近岸到远海 | `Reef_Yucatan02` → `Reef_Yucatan01` → `RA3_ShallowSeaFloor` |
| 城镇 | 紧凑的 `BB_Gravel01` / `Dirt_Yucatan06` 空地，按本图实际范围绘制 |
| 斜坡 | 延续上下台地材质，陡侧面保留岩石，不刷孤立短土斑；见下述山地坡口局部样式 |

纹理变化使用固定种子 2771、9323，尺度 52、17 格；低两层变体阈值为 0.58，第三层裸土阈值为 0.72。四五层的内部统一使用选定岩石，不再生成随机草地或土壤斑块。层界按相邻陆地至少 35 的高差识别。材质边界逐格写入双纹理混合，保留实际来源的子贴片相位。

`Grass_CapeCod01/03/07`、`Grass_Golf01/03/05` 不用于大面积草地填充，避免重复裸土图案与斜条纹；仍被引用的登记保留，未使用项按公共清理规则移除。原贴图与真实渲染核对见 [纹理平铺修复](texture_tiling_fix.md)。

构建准备五层主纹理及前三层变体的原生 diffuse/normal 资源，完成绘制后清除全部未使用项，仅保留实际引用的资源。成品更新追加缺失项后，通过公共封装步骤整理材质编号、保留子贴片相位，并同步原生 `WorldInfo`、XML `WorldDict`、`TerrainTextureAtlas`；最终超过 49 种纹理时拒绝发布。全部可玩来源和生产入口执行同一当前规则，不保留旧图集模式。

## 验证与产物

通用实现位于 `src/terrain/texture_polish.rs`，常规构建和成品更新共享它。测试使用当前河南或合成局部数据，对照普通构建与显式更新结果，逐字节核对非纹理区块及全部玩法位图，并验证旧参数被拒绝且失败不改变原生数据。

`texture-report.json` 记录 `profile`、`palette_revision`、五层主纹理名、新增材质家族、纹理直方图和保留检查。若报告带有 `reference_version: T2.2.9`，它仅是选材研究的来源标签，不指向可恢复地图或旧规则执行模式；当前选材以 `palette_revision` 为准。`textures--comparison.png` 只使用示意颜色，不代替真实视觉核对；生产流程本身不启动游戏或 GUI。

## 山地坡口局部样式

通用 `RAMP_PROFILE` 只接受 `mountain`，缺省相同，自动采用 `surface_style: mountain`；`legacy` 及其他值均拒绝。坡口延续上下台地的实际材质，陡侧面保留岩石，不刷整块灰白铺面或孤立短土斑。`polish-textures` 保留这套局部样式；仅更新坡口表面可使用 `polish-ramp-surfaces`，高度和全部玩法位图逐字节保持。其余地表使用上述 `classic-natural` 规则。实现与验收见[山地坡口](mountain_ramps.md)。


当前仅保留河南当前版的可玩制作源。早期选材研究中的图名和版本号只作资料标签，不代表可用成品、修复下载或旧规则入口；制作按当前[公共约束总表](map_rules.md)、[资源封装](terrain_package_fix.md)与[交付验收](map_acceptance.md)执行。
