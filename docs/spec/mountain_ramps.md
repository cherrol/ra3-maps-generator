# 山地坡道：布局、坡形与材质

遵守[预览边界保护](preview_terrain_lock.md)：制作地图过程中不允许修改层边界、水陆边界，允许添加斜坡。已有合理坡体、坡位、端口和引道继续保护；新增坡道的局部高度及通行变化须留证，不扩大为任意移坡或地形重塑。

## 斜坡数量与通行布局

不设公共坡数配额。预览设计按玩家通往交战区及资源的需要规划坡道；可玩制作可在保持设计分层标签、水陆掩码及其边界的前提下，按实际接入需要添加斜坡。新增坡道须明确位置、宽长、两端标高、坡面剖面和连接关系；不得为开坡移动层界、改岸或搬移既有合理坡道。

出生组及资源在既定及新增合法连接中选址，保护全宽坡体和完整上下引道。主路不便、断路或净宽不足时，可调整本轮布局或添加符合边界保护的斜坡；仍无解则记录冲突。必须移动层界或水陆边界才能解决时，返回预览制作阶段修订基准，不在游戏地图中拓宽、归并或改岸。

## 沿路线选坡位与按层界定朝向

预览设计及可玩制作添加斜坡时，坡位沿预期跨层路线确定，坡轴依据实际低高层界、标高和端口接入，不按对手向量强转。设计数据记录坡体、坡肩、低高端口、宽长及完整引道；可玩阶段新增坡道保留本轮计划与前后差异，不重绘预览追认边界变化。

可玩制作据此选择主次路线并布矿，既有合理坡道的坡心、轴向、宽长及剖面继续保护；新增坡道同样先确定完整坡体与引道，再安排矿位。[斜坡优先级](ramp_clearance.md#斜坡优先级与冲突处理)通过矿位退让落实；找不到布局解时保留失败，不能改坡保矿。

## 通用流水默认

工具所支持的 `RAMP_PROFILE: mountain` 是格式／实现能力，不证明新增斜坡自动满足边界保护。新图转换预览设计并落实本轮新增坡面；已有成品沿用完整原生来源，仅在已确认的新坡范围内写入必要局部高度与导航。工具若会改动设计分层或水陆边界，须停止相关处理并报告。

添加斜坡须选择能够限定新增范围并保留边界的构建或原生编辑方式，独立核对边界与全部实际差异；现有工具成功不代替此项验收。`polish-ramp-surfaces`、`polish-textures` 仍只整理材质，不改变高度与玩法位图。后续构建、冻结和发布由[制作流水](coordinate_pipeline.md)衔接。

## 坡面材质与验收

材质从既定低高台地周围采样，沿实际坡面、坡肩和端口衔接，陡侧保留岩石，不刷孤立短土斑或等宽矩形边框。整理普通／第二混合及存在的悬崖 UV，保留子贴片相位与资源身份，不通过改坡解决材质接缝。

按[地形交接验收](map_acceptance.md#地形交接如何验)核对同版几何、材质、导航和视觉；层边界或水陆边界偏离基准记失败，合法新增坡道的局部高度与连接变化单独留证。边界依据缺失时补齐预览资料，确需变更边界时返回预览阶段。添加斜坡或布局变更后，复验完整坡口、出生组、矿场、赠送及接入，不能以材质更新推定通行合格。
