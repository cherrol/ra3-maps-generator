# 地形资源封装与严格验收

地形编辑、普通构建、坐标成品和发布共用当前资源封装流程。完整原生来源用于保留身份与实际绘制，不豁免资源完整性、当前版本标识、[XML／官方场景严格检查](official_resource_pipeline.md)或任何玩法门禁。当前仅保留河南当前版；已删除成品的修复下载、旧版本入口和原样放行逻辑不再适用。

## 最后一次材质编辑后的同步

`resources::sync_terrain_package` 在最后一次材质编辑后同步以下内容：

- 原生 `BlendTileData` 的材质表及实际引用。
- 原生 `WorldInfo.terrainTextureStrings` 与 XML `WorldDict` 的加载清单。
- XML `TerrainTextureAtlas` 的全部材质声明、贴图文件名和配对资源。
- 当前地图与图集版本 ID；不通过文件夹改名掩盖实际身份不一致。

对象、脚本和原生 `AssetList` 的身份受本轮范围保护；不能仅改 XML、仅补图集或删掉资源声明规避加载问题。发布入口须交叉核对实际材质表、两份加载清单、图集和当前版本信息。

## 清理与引擎上限

`terrain_package::compact` 清除全部未使用的材质家族及未引用、重复的混合记录，并重写主贴图、普通混合、第二混合平面和悬崖 UV 的引用。未超过上限也要清理；最终实际使用材质最多 **49** 种，不能用图集存储容量代替引擎上限。

使用情况包含全部四类引用，不能只检查主贴图。同步移除对应未用图集项并更新加载清单，保留实际绘制效果、混合方向、标志、双侧参数、子贴图相位及全部通行／建造／禁飞位图。`patch_blend` 复用相同描述，避免反复编辑持续追加。完整规则见[纹理清理与数量上限](terrain_texture_rules.md#公共纹理清理与数量上限)。

## 收尾、发布与失败保护

`resources::finalize_terrain_package` 统一完成整理混合表、同步清单、刷新 ID 和校验。先在暂存地图中处理，全部检查通过后才替换调用者的地图；异常 XML 或无效引用不会留下半更新的原生数据。普通构建在纹理修改完成后生成最终资源包，增量地形编辑使用同一收尾步骤。

`map`、`verify`、`accept`、`dist`、安装和 `adopt-coordinate-source` 均按当前严格规则检查。重新封装、来源字节未变或既有发布证明均不能跳过两矿分级、出生点、坡口、朝向、官方几何、XML 和完整资源检查。缺少同版布局时先补齐并核对；不提供无布局旧包或历史参考放行。

失败发生在提交新版本、写入 dist、安装或采用来源之前。提交前失败恢复本轮版本与根蓝图镜像，只清理本轮新产物，保护当前来源；本地成果提交后可选安装失败，则保留已提交成果并明确报告。

## 验证口径

校验可复用一次解包后的原生地图，直接检查材质、混合及悬崖引用；只读检查不克隆或重写整图。完整整理仅用于实际编辑地形的分支。成品核对同时保留原生区块、对象／脚本身份、实际绘制和完整游戏文件一致性证据。

回归使用当前河南或合成局部场景，覆盖新材质缺加载清单、XML 单独缺项、非法版本标识、无效引用、双混合／悬崖引用、重复编辑幂等性和失败不提交。格式解析片段仅用于编解码测试，不能作为旧成品发布的豁免来源。
