# 公共约束总表

本文件统一公共规范、技能与流水的关系、适用范围和规则归属。具体规则在下表指向的专题规范维护；skills 负责选择输入和执行步骤，代码负责计算与拒绝不合格成品，验收报告提供本次执行证据。历史版本记录只描述当时结果。

交战路线宽度与伸入地形、赠送建筑避开伸入区域、赠送生产建筑靠近基地、布矿、坡口、交战区与资源通行便利、整圈岸线、热点双方实际路程和建筑朝向均列入[公共交付验收](map_acceptance.md)必检项。该文件规定证据、状态、联动复查与交付结论；自动结果和独立验收须分别记录。

```mermaid
flowchart TD
  U[本轮用户要求与已确认范围] --> S[skills：选工作流与规范]
  N[专题公共规范：含义与适用范围] --> S
  P[公共 JSON 参数 / 引擎硬上限] --> C[Rust 公共校验]
  M[本图配置、布局、冻结源] --> C
  S --> M
  N --> C
  C --> R[报告：通过、继承、人工核对项]
  R --> D[发布、安装、采用制作源]
```

## 每层负责什么

| 层 | 唯一职责与修改位置 |
|---|---|
| 本轮要求 | 决定交付范围、已确认落点和允许的修改；明确选择可以覆盖设计默认，不能使引擎不支持的地图变为可发布 |
| 专题公共规范 `docs/` | 解释规则含义、取值口径、适用阶段和历史兼容边界；本文是这些规范的总入口 |
| 公共参数 `templates/rules/` | 保存可执行默认参数；距离与预留不能在 skills 中另设一份默认值 |
| 本图输入 `maps/<id>/` | 配置引用与允许的局部覆盖、实际布局、Frame、原生来源、版本和例外证据；不把本图坐标提升为公共参数 |
| 项目 skills | 识别任务、选来源、路由专题规范与工具；不复制阈值表、对置方位列表或版本史 |
| Rust 流水 `src/` | 读取生效参数、计算约束、保护事务、验证完整成品；程序通过只代表报告中实际覆盖的检查 |
| 报告与历史 | 保留输入身份、参数、生效策略及结果；旧报告、旧地图示例不覆盖现行规范 |

出生点、矿位分级和坡口的默认参数统一来自 [coordinate-pipeline.json](../templates/rules/coordinate-pipeline.json)。`src/rules.rs` 从该文件内嵌读取隔离工程的后备默认值，避免 Rust `Default` 再维护一份数字。实际运行仍读取工程自己的参数文件及对应允许的地图覆盖。

引擎硬上限由对应模块的唯一常量维护，例如 `resources::terrain_package::MAX_TEXTURES`；它不是可由地图放宽的距离参数。预览尺寸、格式结构及材质选材分别由下表指定的实现维护，不强行塞入空间参数文件。

## 默认、覆盖、例外与冻结来源

1. **新图／本轮重布**：执行现行规范，先确定地形与通路，再共同选出生点和开局两矿，随后安排扩张阶段、其他资源与赠送点。每项读取其自己的生效策略。
2. **允许覆盖的参数**：公共参数与专题规范定义覆盖入口；`SPAWN_PLACEMENT`、`RAMP_CLEARANCE` 还会启用严格检查。出生平台和矿盘取本图与公共预留的有效下限，不能用较小的局部值取消完整占地。
3. **明确的用户选择**：只影响本轮已授权的设计要求，在本图计划中记录原规则、选择、影响及仍未满足的项。自然语言授权不会自动改变程序参数或令失败报告变为通过；引擎上限与资源完整性仍须满足。
4. **冻结原样重建**：以本图完整原生成品为准。旧空间问题按来源身份继承并拦截新增／恶化；移动了的对象不能继承旧位置问题。未迁移矿位计划不代表符合新分级标准。需要修复或清理时显式制作新版本并重新验收。
5. **规划要求与硬门禁分开**：报告要分别列出自动检查和独立人工结果。总的 `passed`、空间零问题或旧基准，均不能替代尚未覆盖的水陆面积、全周岸线及热点路程核对。

## 冲突处理与维护

- 每项约束只在表中指定的专题维护含义；可执行参数只改公共 JSON 或模块硬常量；skills 通过链接引用，不复制数字表。
- 修改公共参数时，同步解释、实现和行为回归。默认值变更不能只改一个调用处，验收也须读取同一生效策略。参数与内容身份继续参与现有证明／缓存绑定。
- 更新规则关系或入口时维护本表和 [技能索引](map_skills_checklist.md)。历史例子保留原记录；有变化的当前范围需单独说明。
- 本轮核对发现的方位冲突，统一以现行 [出生点规则](spawn_placement.md) 为准。代码新增 `southwest_northeast` 诊断；`southeast_northwest` 仅保留旧报告兼容字段，其点位仍按东西／南北侧别判断，不作为新图对角方案的另一份定义。
- 预览统一按现行正方形标准。旧“河南保留原样”的记录是早先批量更新的历史范围，河南本轮已制作正方形版本，不能据该旧记录继续生成矩形新图。

本表建立统一关系与可查来源，不宣称已把所有文字要求实现为自动检查。仍缺少的公共面积及全周岸线门禁，按上表要求独立验收后再交付；后续实现应进入相应公共模块，而非再复制地图专用脚本。
