# 夹川汇潮纹理平铺修复

2026-10-27，用户实机反馈 T2.2.7 的草地呈整齐重复的斜角裸土块。

原因是美化选材时仅参考名字和示意颜色，将 `Grass_CapeCod03` 当作纯草地变体。解码原版游戏的实际 diffuse 后确认：这张 256×256 贴图本身就是大面积裸土与草地的斜角过渡。整片平铺自然会重复该图案，并非高度场产生三角地形。之前的材质编号、打包和位图测试不能发现这个视觉问题。

T2.2.8 曾试用 `Grass_Golf05` 替代第一层变体，但真实渲染仍出现明显斜条纹，因此未安装该候选；检查其 normal 贴图后将其排除。最终 T2.2.9 沿用成品重绘纹理：

- 第一层变体换成已检查原图与真实渲染的 `Grass_CapeCod05`，第二层变体采用 `Grass_Geneva01`。
- 高层使用较均匀的 `Grass_CapeCod05/12`，减少裸土覆盖；`Dirt_Iceland05` 从 64,879 格降至 28,082 格。
- 美化结果不再使用 `Grass_CapeCod01/03/07` 或 `Grass_Golf01/03/05`，回归测试检查它们的实际使用数量为零。原图图集仍保留这些资源的登记，避免改变资源编号。
- 高度、全部通行与建造位图、对象、脚本和资源清单保持逐字节一致。35 项自动测试通过。

原始材质检查记录保存在 `work/texture-debug/inspected-textures.json`。纹理直方图与数据保留检查位于新版 assets 的 `texture-report.json`。WorldBuilder 真实 D3D9 鸟瞰图与渲染核对保存在同目录；这类渲染仍不等同于游戏实测。

后续选材须先看游戏原始贴图，再查看真实渲染。示意配色图只能核对空间分布，不能用来判断纹理细节、平铺周期或草土边界是否美观。
