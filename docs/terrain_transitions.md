# 地形交接：斜坡、层界与水陆边界

本规范统一三类边界及交汇处的处理。2026-10-30 按用户要求复查 AXAI 原生提取数据和已有 WorldBuilder 渲染，并补充 NKL、SMAI 交叉核对，将观察落实到预览、可玩制作、增量编辑和交付验收。坡位与坡形仍见[山地坡道](mountain_ramps.md)，水体归层及全周范围见[公共预览](terrain_preview.md#小水域的单层包裹)，选材见[纹理规范](terrain_texture_rules.md)，证据与判定见[地形交接验收](map_acceptance.md#地形交接如何验)。

## AXAI 参考说明

研究样本为麦格马戈登、新麦格马戈登 v1.4、古城危机 xex 2.1、遗忘之地 v1.02、黄金树之影 0.53。核对原生高度、基础材质、通行位图与混合平面；视觉比较使用黄金树、新麦格马戈登和遗忘之地已有的 WorldBuilder 总览。输入身份、坐标和测量口径保存在[参考证据](terrain-transitions-reference/evidence.json)，[局部图](terrain-transitions-reference/axai-details.png)为原渲染裁切，仅用于外观比较。既有渲染未重新导出，未证明与本次原图同版；原生测量与外观观察分别解释，不合并为同版验证。

| 参考部位 | 实际观察 | 转为本项目的做法 |
|---|---|---|
| 黄金树的自然坡口与不规则台地 | 岩壁在坡口中断并接回两侧；坡面与上下地表相连，中央人工平台使用另一套明确的建筑语言 | 连同坡肩、上下端口和台地一起设计；自然坡口与人工道路分别处理 |
| 新麦格马戈登的山脚、沙岸与岩岬 | 土路、草地、山岩各有连续主体；沙滩沿岸变化，在岩岬附近收束；近岸与外海海底有不同材质 | 材质范围服从实际坡面、崖面和岸坡，交汇处联合收口，避免按独立距离带互相覆盖 |
| 遗忘之地的自然岸与人工港岸 | 沙岸与港口铺装、挡岸有不同边界表达 | 先声明边界类型与预期通行，再选对应几何和材质，不能把所有水边刷成同一条沙带 |

原生高度与位图可以支持静态测量，渲染只支持可见形状、颜色和铺面连续性的观察。自然外观不证明可通行，海底颜色也不证明水深。参考图的道路、岸线有局部人工或陡岸设计，不能据此取消本项目适用小岛、小水域的全周双向过渡要求。参考中的坐标、尺寸、层高、材质配色和纹理数量均不提升为公共默认；当前五层选材、Frame 和通行规则继续生效。

复查时先按证据中的 SHA-256 确认本地原图身份，使用只读 `unpack <原图.map> -` 解压到标准输出，再按[原生格式](ra3_map_format_spec.md)读取高度、`BlendTileData` 和 `StandingWaterAreas`，不加载参考图为制作配方。字段布局、翻 Y 口径及图像裁切范围随证据保存。`work/` 中的缓存路径仅是研究来源标签，公共规范和已归档测量不以这些缓存作为构建依赖；未收录外部地图的完整原件。

## 联合设计的范围与顺序

给每条坡道、层界段、岸线段及交汇处分配可追溯 ID，记录两侧区域、预期移动域、连接或阻断意图及修改范围。按本图实际高度、拓扑和路线分类为可通行坡道、不可通行层界、连续水陆过渡，以及经适用性核对的自然陡岸／岩岬或人工边界；颜色不同不等于地形类型不同。

设计时先找坡口接层界、层界抵岸、坡口近岸、三层交点、岸线凸角／凹角与窄颈。先解决这些位置的接入和收边，再展开各段；生成时以已确认的联合过渡范围约束各次写入，不能靠最后执行的岩石、沙地或坡面刷子覆盖前一阶段。顺序为：**边界分类与空间预留 → 主路和完整坡口 → 实际高度 → 导航及双向接入 → 全部占地叠加 → 材质与混合 → 同版回读和外观核对**。这是设计和复核顺序，不是另设一套 CLI 构建阶段。

保留台地内部的平坦可建空间、来源地形主体及本轮范围外内容。局部圆整只修折脊、尖角、单格台阶和异常锯齿，不将全部层界抹成可翻越缓坡，也不为营造自然感把通行中央改成凹凸路面。净宽、坡矿优先、伸入整理、出生组和完整建筑预留继续按各专题执行，不新增一组统一过渡宽度或坡度数字。

## 斜坡与台地接合

- 纵向从低台地落地段经过完整坡体接到高台地，中央坡度稳定，两端平顺接入；同时核对全宽平行剖面。中央一条线平滑不能证明两边没有折脊、悬边或端缝。
- 侧向在完整通行宽度之外收拢坡肩，接回原有岩壁和台地轮廓；岩壁在实际开口处中断，不能横穿端口，侧边也不能形成可钻出的错误捷径。圆整肩部不得缩窄、削短坡道或侵占完整引道，坡矿冲突按[优先级](ramp_clearance.md#斜坡优先级与冲突处理)移矿。
- 坡面延续实际上下地表，材质变化结合周围形状渐接，不在坡体边框刷等宽碎石框，也不在几何中点横切一条生硬的上下材质分界。原有连续道路穿过坡口时按实际路线衔接，不凭空增加孤立短土斑。
- 从本图最新完整原生来源修坡，分别记录高度、导航、材质的实际改动。`polish-ramp-surfaces` 只完成表面工作，不能作为坡形整改证据。

## 层与层交接

不可通行层界保留清楚的高低关系和连续崖面。上缘、崖面、崖脚分别接到对应台地；处理折角和层界端头时避免针状突起、孤立高格、锯齿裂口和无用途的窄槽。坡道开口附近按上一节联合处理，不让自动岩带重新封住坡口。

岩石主要落在实际陡侧面及合理的崖顶／崖脚过渡，内部平地继续使用该层地表。沿真实轮廓变化，不能把岩壁仅表达成平地上的一圈等宽描边。核对陡面贴图的朝向、相位和拉伸；有原生崖面 UV 或多材混合时保留或正确重建，不能只改主贴图索引而遗留指向旧材质的细框。石块和植被可辅助收边，但必须服从完整占地与通路，不能用装饰遮住错误几何。

三层交点按实际邻接关系分别接合，避免低层穿入高层留下薄片或多条岩带叠成结块。断开的台地、禁行边界和可通行开口均须在实际高度与导航中一致，不能只在图上表现。

## 水陆交界

先落实水体掩码、归属陆地层和实际水面高度，再沿岸法向设计“陆地平台 → 陆侧岸坡 → 水线 → 水下浅滩 → 外侧水底”的连续剖面。宽度按本图高差、曲率及移动能力确定；岸边刷了几格沙地与具备足够的可通行岸坡是两件事。不得把高台地直接接低水底的断层用沙纹理掩盖，也不能只抬水下地形就声称陆侧过渡已完成。

自然缓岸按实际岸坡、湿润带和深浅水底接材质，沙带可随岸形变化，不能在整圈画相同宽度的亮色框。岩岬或人工岸只在已声明且符合当前适用规则的位置使用；到沙岸的连接须有连续收束，不能留下沙地爬满陡壁、岩带切断浅滩、岸线单格缝和孤立沙片。颜色只表达材质，水深与通行以原生几何和导航测量为准。

适用小岛、小水域仍按[全周规则](terrain_preview.md#小水域的单层包裹)落实每段双向过渡；跨层水域先按调整前接岸长度选层，并使其他层界绕开整圈岸线。新留的岩岬、装饰或建筑不能成为漏验段。开放海域、跨框水体及人工港岸逐处记录适用性，不能引用 AXAI 外观自动获得例外。

坡口接近岸线时一起核对高低端、陆路引道、岸坡和水路余量；层界抵岸时核对崖脚、水线及缓岸的连接。不同移动域分别记录可走范围，不能用两栖路径替代普通陆军或舰船各自的接入要求。

## 材质、混合与导航须对应同一几何

过渡范围先由几何决定，再选材。当前 `classic-natural` 五层主材继续使用；借鉴 AXAI 的连续处理方式，不照搬其整张纹理表。检查主材、普通混合、第二混合平面和悬崖 UV，既清理旧引用，也保留未修改区域的合法混合、相位和资源身份。三材交点、斜向边界及凹凸角必须单独核对，普通二材边缘看起来正常不能推定这些位置正常。

高度改动后复算坡度及受影响导航，按目标移动能力核对正反向接入。纹理变化不应偷偷更改高度、导航、对象或脚本；有意修改时须单列差异。最终将全部矿盘、旋转矿场、建筑及赠送主备／条件分支的完整占地、出口和接驳叠加到同一几何上复验，不能等到表面完成后再通过缩窄坡口或岸坡迁就布局。

## 各阶段如何使用

| 阶段 | 应落实的内容 |
|---|---|
| 真实资料与纯预览 | 保留原始高程和来源岸线；在实际设计数组上处理归层、窄颈和伸入，声明过渡类型与空间预留。分层色块尚未表达最终坡形、贴图或导航，不据此填写可玩通过 |
| 推进新可玩图 | 将设计转为 `LAYERS`／`LAYOUT` 及本图实际构建输入；先定主路与全宽坡口，再叠加资源和出生／赠送空间，完成联合高度和导航后整理表面 |
| 已有成品修改 | 从冻结完整 ZIP 读取实际几何及混合，按本轮范围选择坡形、坡位、表面或纹理入口；发现工具未能完成的岸坡／交汇整改，保留候选和失败位置，落实原生编辑后再验，不用旧蓝图覆盖 |
| 构建后处理 | 核对岩带、沙带、坡面刷写的交集及第二混合／崖面数据；纹理封装继续清除全部未使用项并同步声明，执行公共数量上限 |
| 验收、冻结及发布 | 按[交接验收](map_acceptance.md#地形交接如何验)汇总同版逐段证据，补足旧记录未覆盖的判据，通过后才采用来源；冻结重建须保持已验过渡及游戏文件 |

## 当前自动覆盖与缺口

以下结论描述当前实现的覆盖范围；单项工具成功不代表整图已通过交接验收：

| 实现 | 实际覆盖与限制 |
|---|---|
| `terrain_preview/mod.rs` 的层高生成 | 预览以固定层高和水底表达设计分层，不能提供实际岸坡与混合证据 |
| `terrain/mod.rs` 的 `landing_coasts` | 只在配置范围抬升部分水下地形，没有自动完成从陆台到水底的全周连续岸坡 |
| `terrain/surface.rs`、`ramps/geometry.rs` 的岸边导航 | 坡道／配置岸区之外有默认封岸逻辑；后续改坡也须复查岸线是否被重新封闭 |
| `ramps/mountain.rs`、`ramps/geometry.rs` | 已有中央稳定坡面、端部缓接、坡肩收拢及全宽坡形检查；不能据此推定全图层界／岸线均合格 |
| `texture_polish.rs` 的距岸／距崖选材 | 尚未建立坡口、层界与岸线交汇处的联合过渡模型；固定带和噪声不能代替几何分类 |
| `ramps/surface.rs::patch_blend` | 局部清理三组混合后主要按首个异材邻格重建普通二材混合，未完整重建多材交点和悬崖 UV |
| `ramps/material_joins.rs` | 按[显式成品计划](production_placement_fix.md#已有成品的受阻修复与重选)沿指定坡口的同材质对边界补普通混合，保护主材相位、第二混合、悬崖与玩法位图；复杂状态拒绝或明确保留自然端部后独立复核，不等同于通用多材交汇修复 |
| 纹理整理、封装修复和普通重包 | 纹理整理保护高度及玩法位图；封装完整性或重包成功均不能证明坏坡、岸坡或导航已修复 |

尚无覆盖全部交汇几何、多材混合及全周岸线的公共自动修复／门禁。当前由专业验收补足，已知问题记失败、缺证据记待核验；后续自动化应进入上述公共模块并增加实际行为验证，不复制地图专用修补脚本，也不把规范写入等同于自动落实。
