# 更新方法

> 原文：https://www.yuque.com/muzeqaq/ra3mapwiki/px5ysionwi93613d
> 目录位置：Lua库 (推荐使用)（先看安装使用流程！！）



# 第一种 通过地编伴侣
在地编伴侣设置中绑定了lua库路径后, 若lua库有更新, 会直接推送, 根据提示更新即可

# 第二种 通过文件覆盖
将lua库的文件夹(RA3CoronaMapLuaLib)删除, 并在网盘或github上下载最新的版本, 解压后放回原来的文件夹即可
