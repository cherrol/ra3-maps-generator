# 03_聊天信息与单位创建

> 原文：https://www.yuque.com/muzeqaq/ra3mapwiki/edbts1w9gza2zaxd
> 目录位置：Lua例子/代码示例

监控聊天信息的功能只能在多人游戏, 或者单开局域网房间时才有效

只有当输入的文字前带 '/'

在本例子中, 聊天中分别输入/1, /2, /3会生成不同的单位



![](https://cdn.nlark.com/yuque/0/2025/png/34558013/1738658960497-1dad009b-8f8f-46a0-acba-9b2f48d0272d.png)



首先, 在想要生成单位的地方新建一个路径点  
![](https://cdn.nlark.com/yuque/0/2025/png/34558013/1738659051335-cbdb7d27-9fa2-4f0b-8ba5-7be18fe5b279.png)



# 使用lua库
```lua
ChatMsgModule.register_chat_listener(
    function(player_name, content)
        ChatMsgModule.print_on_chat(player_name .. " said: " .. content)

        local thing = ''

        if content == "1" then
            thing = ThingEnum.AlliedAntiVehicleVehicleTech3 -- 幻影坦克
        elseif content == "2" then
            thing = ThingEnum.CelestialFighterAircraft -- 凤凰战机
        elseif content == "3" then
            thing = ThingEnum.AlliedCommandoTech1 -- 谭雅
        else
            ChatMsgModule.print_on_chat("未知命令")
            return
        end

        UnitCreateHelper.create_unit_at_waypoint(
            UnitHelper.get_unit_auto_name(),
            thing,
            TeamModule.from_player_name(player_name),
            "Waypoint 3",
            nil, nil, nil
        )

    end
)
```

# 使用原生api
```lua
-- 全局变量, 用于生成不重复的unit_name
index = 1
function onUserShortChatMsg(player_name, content)
    exMessageAppendToMessageArea(player_name .. " said: " .. content)
  
    local thing = ''
  
    if content == "1" then
        thing = 'AlliedAntiVehicleVehicleTech3' -- 幻影坦克
    elseif content == "2" then
        thing = 'CelestialFighterAircraft' -- 凤凰战机
    elseif content == "3" then
        thing = 'AlliedCommandoTech1' -- 谭雅
    else
        exMessageAppendToMessageArea("未知命令")
        return
    end
  
    ExecuteAction("CREATE_NAMED_ON_TEAM_AT_WAYPOINT", 
    "created_unit" .. tostring(index), 
    thing, 
    player_name .. "/team" .. player_name,
     "Waypoint 3")
  
    index = index + 1

end
```
