# 1_日志系统

> 原文：https://www.yuque.com/muzeqaq/ra3mapwiki/nluv89iekbhc3pwp
> 目录位置：Lua库 (推荐使用)（先看安装使用流程！！）/代码样例

:::success
作者: dreamness

:::

使用日志, 可以方便排查脚本中的问题, 观察各个变量的状态



日志系统共有4个目标端:

+ DEBUG_LOG_FILE  新地编调试工具的日志文件<font style="color:#74B602;">(地编路径\NewWorldBuilder\game\logs)</font><font style="color:#DF2A3F;"> (默认)</font>
+ DLL_LOG_FILE  日冕客户端的enhance dll输出的日志文件(不建议, 会在玩家的电脑上生成,影响性能)<font style="color:#74B602;">(日冕客户端路径\CoronaData\Logs)</font>
+ PUBLIC_BOARD  公屏<font style="color:#74B602;"></font>
+ CHAT_MSG 多人游戏聊天框<font style="color:#74B602;"></font>



日志共有5个等级

+ TRACE
+ DEBUG
+ INFO<font style="color:#DF2A3F;">(默认)</font>
+ WARN
+ ERROR

日志等级越高, 代表信息更重要, 如果当前的日志等级大于输出的日志等级, 则日志不会输出



建议可以在地图开发阶段将日志级别调低

在发布前将日志级别条高, 并且记得一定要移除输出目标_**CHAT_MSG**_,_**DLL_LOG_FILE**_以及 _**PUBLIC_BOARD **_



```lua
--- 设定日志级别为info
--- 设定输出目标, 同时在4个目标上输出日志
--- 全局设置一次就行了
LoggerModule.setup(LoggerLevelEnum.INFO, 
            {
                LoggerTargetEnum.DEBUG_LOG_FILE, 
                LoggerTargetEnum.DLL_LOG_FILE, 
                LoggerTargetEnum.PUBLIC_BOARD,
                LoggerTargetEnum.CHAT_MSG
            })

--- 输出一条info级别的日志
--- 第一个参数pos代表这条日志产生的位置, 便于排查问题
--- 第二个参数msg是日志内容
LoggerModule.info('logger_demo.lua', 'a info log')

--- 输出一条warn级别的日志
LoggerModule.warn('logger_demo.lua', 'a warn log')

--- 输出一条error级别的日志
LoggerModule.error('logger_demo.lua', 'a error log')

--- 这条日志不会被输出, 因为日志级别是info
LoggerModule.debug('logger_demo.lua', 'a debug log')

--- 忽略日志等级, 强制在聊天框输出一条日志
LoggerModule.log('a forced log', LoggerTargetEnum.CHAT_MSG)
```
