# 拼模的首要任务
拼模的首要任务是选定一个**本体**，接下来的所有附属单位都将基于本体进行调整。  

## 简单模型拼接（直接复制位置）
以基洛夫（`object1`）为本体，将航空母舰（`object2`）粘贴到基洛夫的正中央位置：  

```lua
local x, y, z = ObjectGetPosition(object1)
ObjectSetPosition(object2, x, y, z)
```



结果如下：  

![](https://cdn.nlark.com/yuque/0/2024/png/50038568/1731759995078-b504a2e9-5264-4240-94bb-16bbe72ab20b.png)

![](https://cdn.nlark.com/yuque/0/2024/png/50038568/1731759994019-79556022-0c2e-4bbd-a3d1-b3e3f033e13d.png)

+ 航母成功移动到基洛夫的位置。  
+ **但无法与基洛夫保持相同方向。**

要解决方向一致问题，需要更高级的操作，不仅包括坐标信息（X, Y, Z），还包括方向向量。



## 进阶模型拼接（使用单位矩阵）
所谓单位矩阵（**此文特指包含单位坐标、旋转和缩放信息的矩阵**），可通过以下方法获取：  

```lua
local matrix = ObjectGetTransform(object1) -- 获取 object1 的单位矩阵
ObjectSetTransform(object2, matrix)       -- 将 matrix 赋值给 object2
```

效果：  

通过脚本帧循环执行，即可达到航空母舰的位置与方向总是与基洛夫相同，即达到所谓的拼模了

![](https://cdn.nlark.com/yuque/0/2024/png/50038568/1731760004582-ebb3a764-2f91-43a8-889e-9f6fdaffb534.png)![](https://cdn.nlark.com/yuque/0/2024/png/50038568/1731759995104-011469ad-79d0-4c21-a5c0-80876aa1e190.png)

### 1. 基洛夫右前方拼模问题
假如想在基洛夫的**右前方**添加一个水翼船（`object3`）：  

1. **假设坐标系**  
    - 红警地图是一个巨大的直角坐标系。  
    - 若基洛夫位置为 `(x, y)`，角度为 0°，右前方的位置为 `(x+50, y-50)`。

![](https://cdn.nlark.com/yuque/0/2024/png/50038568/1731759996305-6112f486-c432-41ee-a2f0-1ae5c209b5db.png)

2. **尝试修改单位矩阵中的坐标值**  
将基洛夫的单位矩阵赋值给水翼船，并修改坐标：

```lua
local matrix2 = {
    matrix[1], matrix[2], matrix[3], matrix[4] + 50,
    matrix[5], matrix[6], matrix[7], matrix[8] - 50,
    matrix[9], matrix[10], matrix[11], matrix[12]
}
ObjectSetTransform(object3, matrix2)
```

![](https://cdn.nlark.com/yuque/0/2024/png/50038568/1731760003897-3e233f8f-071b-4c45-ac94-58b6c32ca049.png)![](https://cdn.nlark.com/yuque/0/2024/png/50038568/1731759999672-1faada2a-b08d-454c-8034-be8eb3b9920e.png)![](https://cdn.nlark.com/yuque/0/2024/png/50038568/1731760000050-2c530527-daac-4a7d-a283-0bc5908d8af2.png)

结果：  

+ 水翼船一开始在基洛夫右前方，随基洛夫移动并转向。  
+ **但很快水翼船跑到基洛夫的左后方，与预期相反。**

原因：  

+ 水翼船始终以基洛夫为基准，按固定量平移 `(+50, -50)`，而基洛夫的“右前方”随着旋转动态变化，因此简单修改坐标无效。

### 2. 探究单位矩阵的含义


下面是基洛夫角度分别是0°；90°；180°时的单位矩阵

![](https://cdn.nlark.com/yuque/0/2024/png/50038568/1731760000614-5d1b7f4d-b266-41b0-8a76-7b95479586dc.png)

![](https://cdn.nlark.com/yuque/0/2024/png/50038568/1731760004479-e381d29f-e875-4a27-a10a-d845073a9605.png)![](https://cdn.nlark.com/yuque/0/2024/png/50038568/1731760005450-2f2f524e-a4db-42de-96d6-81974b83d9a4.png)

单位矩阵的形式如下： 

```plain
┏               ┓
┃ m11 m12 m13 X ┃
┃ m21 m22 m23 Y ┃
┃ m31 m32 m33 Z ┃
┗               ┛
```

+ `X, Y, Z`：单位在地图中的坐标。  
+ `m11, m12, m21, m22`：控制单位2D方向的旋转矩阵。



在刚刚3个图片中，仅仅改变基洛夫的方向我们发现，m13,m23,m31,m32,m33都是不变的，因此我们得出，m11,m12,m21,m22是控制单位2D方向的数字，那我们单看这四个数字

再仔细看，基洛夫0°时的矩阵是



+ **0°：**  

```plain
┏     ┓
┃ 1 0 ┃
┃ 0 1 ┃
┗     ┛
```

是不是非常特殊？没错！他就是平面直角坐标系里的基向量！



同时我们看90°矩阵

+ **90°：**  

```plain
┏      ┓
┃ 0 -1 ┃
┃ 1  0 ┃
┗      ┛
```

（注：***e-008是非常接近0的数字，可近似看为0）

而这个矩阵正是逆时针旋转90°的旋转矩阵！

同理180°矩阵

+ **180°：**  

```plain
┏       ┓
┃ -1  0 ┃
┃  0 -1 ┃
┗       ┛
```

该矩阵的功能正是旋转180°的旋转矩阵。





#### 结论：
因此我们发现，单位矩阵

```plain
┏               ┓
┃ m11 m12 m13 X ┃
┃ m21 m22 m23 Y ┃
┃ m31 m32 m33 Z ┃
┗               ┛
```

中， `m11, m12, m21, m22` 为记录单位平面方向的**旋转矩阵**。

### 3. 水翼船的动态坐标计算
当基洛夫旋转后，水翼船的坐标是相对基洛夫的局部坐标系，而单位矩阵需要使用全局地图坐标系。



前面所说，基洛夫是我们的本体，我们能确定的是一开始水翼船相对基洛夫的位置，这时我们是默认水翼船与基洛夫在同一直角坐标系中的

![](https://cdn.nlark.com/yuque/0/2024/png/50038568/1731760017790-44980e98-f73a-4bb7-b30d-acdb67a938cb.png)

而随着基洛夫旋转，基洛夫与水翼船就属于不同的直角坐标系了

![](https://cdn.nlark.com/yuque/0/2024/png/50038568/1731760044279-52b6e44c-8f40-438d-931b-b468958dc285.png)



水翼船的坐标向量

```plain
┏     ┓
┃  50 ┃
┃ -50 ┃
┗     ┛
```

其实是建立在以基洛夫为原点的坐标系中的，而我们最终给水翼船单位矩阵赋值是基于地图所用的坐标系。

那如何得到水翼船基于地图坐标系的坐标向量呢？答案是用基洛夫的旋转矩阵乘水翼船的坐标向量，得到的就是水翼船在地图坐标系中的坐标向量了，当然别忘记要加上基洛夫的坐标向量。

**转换方法：**  
使用基洛夫的旋转矩阵与水翼船的相对坐标向量相乘，再加上基洛夫的全局坐标：  

```plain
┏           ┓          ┏     ┓                            
┃ m11 m12   ┃    *     ┃  50 ┃
┃ m21 m22   ┃          ┃ -50 ┃                           
┗           ┛          ┗     ┛  
```

计算得到水翼船在地图坐标系的全局位置，并将其更新到水翼船单位矩阵中。



![](https://cdn.nlark.com/yuque/0/2024/png/50038568/1731760017131-86f89d31-447e-419a-a9af-30fd2205ede7.png)



如果说2x2矩阵表示的是2维平面上单位的旋转矩阵，那么3x3矩阵正好表示的是3维空间中单位的旋转矩阵，所以如果考虑加上Z轴依旧可以用此原理思考，但是因为我没有实践3维变换，所以暂时不敢下定结论

## 通用公式
总之，上面是我对单位矩阵原理的探究，如果看不懂也没关系，我整理出了一个公式可供大家使用：

设本体的单位矩阵为：  

```plain
┏               ┓
┃ m11 m12 m13 X ┃
┃ m21 m22 m23 Y ┃
┃ m31 m32 m33 Z ┃
┗               ┛
```

附属单位在本体角度为 0° 时的相对坐标为 `(x0, y0)`， 绝对坐标是`（X+x0，Y+y0）`。

**实时单位矩阵计算公式：**  

```plain
┏                                       ┓
┃ m11 m12 m13 X + (m11*x0 + m12*y0)    ┃
┃ m21 m22 m23 Y + (m21*x0 + m22*y0)    ┃
┃ m31 m32 m33 Z                        ┃
┗                                       ┛
```

---

以上公式适用于拼模场景，直接使用即可完成动态调整！
