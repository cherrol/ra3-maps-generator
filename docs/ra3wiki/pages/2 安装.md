# 2 安装

> 目录位置：Python库

:::success
作者: dreamness

:::

确保有python3环境

# 安装或升级
```bash
pip install --upgrade ra3map
```



如果遇到网络问题, 可以尝试使用国内源来进行安装,

如使用清华源:

```bash
pip install -i https://mirrors.tuna.tsinghua.edu.cn/pypi/web/simple --upgrade ra3map
```

# 引入依赖
```python
from ra3map import Ra3Map
```
