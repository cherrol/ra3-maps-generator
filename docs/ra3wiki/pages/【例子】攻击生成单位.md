# 【例子】攻击生成单位

> 原文：https://www.yuque.com/muzeqaq/ra3mapwiki/oo20m7mvz42g2ql4
> 目录位置：Lua例子

:::info
作者：**acgion**

:::

这次带来一个lua实例，其效果是生异形  
其实现逻辑是通过条件判定函数来执行  
首先介绍一下这里使用的条件脚本 Named object has object status.某物体有某状态.[59]  
【59】Object 'liandao' has Object Status is 'IS_FIRING_WEAPON'  
判断单位是否具有某状态的条件脚本，有俩个参数，一个是单位一个是状态  
然后，我们来看看“生异形”可以用到什么脚本  
23号单位生成脚本或36号单位在某点生成脚本  
【23】Spawn object 'SovietScoutVehicle' in Team 'Player_1/Team' at position ((0.00,0.00,0.00)), rotated 0.00 degrees .  
【36】Spawn unit of type 'SovietScoutVehicle' on Team 'Player_1/Team' at Waypoint 'aaa'  
对于23号脚本来说地编上用处并不多因为位置是定死的并不能随机改变，而36号脚本用的更多用于流线图点位刷兵  
而对于lua来说，除了地编内的常用的几个脚本，23号的位置生成也非常有用了，他可以在某单位位置附近随机生成单位，通过获取单位位置然后使用伪随机数函数来生成一个伪随机数，而后通过将位置参数填入位置（xyz）这样就可以在单位周围随机生成单位。  
使用地编函数制造一个可以生异形的镰刀大致如下  
-----如果-----  
【59】 Object 'liandao' has Object Status is 'IS_FIRING_WEAPON'  
-----那么-----  
【36】Spawn unit of type 'SovietScoutVehicle' on Team 'Player_1/Team' at Waypoint 'aaa'  
-----否则-----  
使用通过条件函数判定是否是开火状态，然后就在指定位置生成单位，如果使用lua来生异形的话可以这样：



```lua
#!ra3luabridge  
if EvaluateCondition("UNIT_HAS_OBJECT_STATUS", "liandao", "IS_FIRING_WEAPON") then--59号地编条件判定函数  
    local object = GetObjectByScriptName("liandao")--日冕lua，获取liandao的信息  
    local x, y, z = ObjectGetPosition(object)--获取liandao当前位置  
    local x1=ceil(GetRandomNumber()*500)  
    local y1=ceil(GetRandomNumber()*500)--获取范围在0-500的伪随机数  
    ExecuteAction("CREATE_OBJECT",'SovietScoutVehicle','Player_1/Team',{X=x+x1,Y=y+y1,Z=z},"0")--调用23号脚本，在单位位置x,y的+0-500范围内随机生成  
end
```



这里是通过23号spawn object脚本生成位置随机的单位的lua脚本写法，当然，要是想与上面地编逻辑完全一致的话也简单，如下



```lua
if EvaluateCondition("UNIT_HAS_OBJECT_STATUS", "liandao", "IS_FIRING_WEAPON") then--59号地编条件判定函数  
    ExecuteAction("CREATE_UNNAMED_ON_TEAM_AT_WAYPOINT",'SovietScoutVehicle','Player_1/Team'，"aaa")--调用36号脚本  
end
```



这就完成了，一样的逻辑结构一样的效果，唯一区别是，使用lua脚本时可以通过改变参数来达到实时修改脚本，而无需构建多条脚本，使脚本具有高复用性。  举个例子：



```lua
numes=1 --数字，用于单位名称数字自增例如a1 a2  
nas="a" --字母，用于单位名称拼接名字时候避免重复  
function GenerateUnitName(objectname,teamname,position)--函数，可以反复调用  
    local ns=a..numes--拼接单位名称  
    ExecuteAction("CREATE_NAMED_ON_TEAM_AT_WAYPOINT",ns,objectname,teamname,position)--35号刷兵脚本在lua的用法  
    numes=numes+1--数字自增+1，重复调用函数时使每个名字不一样  
    return ns--返回值，这里返回的是单位的名称  
  end
```



这是一个35号脚本函数化使用，通过定义一个函数来达到复用脚本的目的，每次使用只需要将单位名，队伍名，位置参数传入，即可快速生成单位，而不需要启用一次写一条脚本，并且每生成一个都会返回一次单位名，这个单位名在自定义情况下不会与已有单位名重复，带返回值的函数使用方法如下：



```lua
local name = GenerateUnitName(objectname,teamname,position)
```



它根据你所设定的单位名objectname来生成目标单位，teamname是队伍名，postion是目标点位，name则是生成单位后返回的单位名称，可以在地编脚本内使用，改血，位移或其他使用到单位名字的脚本均可
