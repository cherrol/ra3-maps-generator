# 11_文本框

> 原文：https://www.yuque.com/muzeqaq/ra3mapwiki/oigo98mvdi9d4m96
> 目录位置：Lua库 (推荐使用)（先看安装使用流程！！）/代码样例

![](https://cdn.nlark.com/yuque/0/2024/png/34558013/1734867392721-ca4a6dad-d077-4b79-8638-f9c54e49ab71.png)

需要先在地图文件夹(不是lua文件夹)中, 新建map.str文件, 并确定使用utf8编码

输入以下内容并保存

```lua
MSG:TITLE
"标题~"
END

MSG:UNIT_MSG
"单位消息文本"
END
```



```lua

MsgBoxModule.show_msg_caption("MSG:TITLE", 10, nil)
MsgBoxModule.show_msg_box_on_unit("test_unit", "MSG:UNIT_MSG", 10, ButtonTextureEnum.Button_AlliedAntiGroundAircraft_on)
SchedulerModule.delay_call(function()
    MsgBoxModule.remove_msg_box_on_unit("test_unit")
end, 15 * 5)
```
