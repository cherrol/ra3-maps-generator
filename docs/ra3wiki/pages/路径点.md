# 路径点

> 原文：https://www.yuque.com/muzeqaq/ra3mapwiki/qhgxb7la3vm4ymgh
> 目录位置：C#库



# 创建/获取/删除


```csharp

// 新建一个路径点
var w1 = ra3map.AddWaypoint("w1", 100.1f, 200.2f);


// 为玩家5创建出生点
var wp5 = ra3map.AddPlayerStartWaypoint(5, 1000.1f, 800.2f);

// 获取所有的路径点
List<WaypointWrap> waypoints = ra3map.GetWaypoints();

// 移除一个路径点
ra3map.Remove(w1);

```



# 获取详情 / 修改路径点
```csharp

w1.WaypointName = "ww1";

w1.Position = new Vec3D(200.1f, 200.2f);

w1.WaypointType = 1;
```
