# 14 计数器

![](https://cdn.nlark.com/yuque/0/2025/png/34558013/1736089310967-84682bae-bf78-4b69-b6e3-534137eb9833.png)

设定计数器和计时器

+ 支持设定计数器和计时器的文本显示
+ 支持显示/隐藏计数器和计时器
+ 支持获取/修改计数器的值
+ 不支持获取/修改计时器的值

```lua
-- 以下代码执行一次即可
-- 设定计数器的初始值
CounterModule.set_counter_value("counter_1", 10)
-- 显示并设置计数器的文本
CounterModule.show_counter("counter_1", "COUNTER:counter_1")
-- 显示并设置计时器的文本
CounterModule.show_timer("timer_1", "TIMER:timer_1")


-- 以下代码需要每帧执行
-- 实现每秒计数器+10
if mod(GameModule.get_frame_number() , 15) == 0 then
    local n = CounterModule.get_counter_value("counter_1")
    n = n + 10
    CounterModule.set_counter_value("counter_1", n)
end
```

另外需要编辑map.str, 设置文本内容, 注意编码应为utf8

```lua
COUNTER:counter_1
"计数器1"
END

TIMER:timer_1
"计时器1"
END
```
