# 玩家

> 原文：https://www.yuque.com/muzeqaq/ra3mapwiki/xd28gtma3aewo07a
> 目录位置：C#库

# 创建/获取/删除
```csharp
// 创建玩家
var player1 = ra3map.AddPlayer("Player_1");

// 根据名字获取玩家
var player = ra3map.GetPlayer("Player_1");

// 获取所有玩家
List<PlayerData> players = ra3map.GetPlayers();

// 删除玩家
ra3map.Remove(player);

```

# 获取/修改玩家详情
```csharp
var player1 = ra3map.AddPlayer("Player_1");

player1.Color = "Blue";
```
