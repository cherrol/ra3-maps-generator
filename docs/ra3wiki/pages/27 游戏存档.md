# 27 游戏存档

> 原文：https://www.yuque.com/muzeqaq/ra3mapwiki/td7zxzt9eme7scyo
> 目录位置：Lua库 (推荐使用)（先看安装使用流程！！）/代码样例

存储和读取游戏数据两部分都要实现

# 存储游戏数据
## 存储数据
传入一个函数, 在触发存档时会自动调用, 将返回值存下来

不支持userdata, function, 或包含它们的table

```lua
-- 假设有存放游戏状态的全局变量 game_status_tbl , player_stat

ArchiveModule.set_save_data_function(
  function()
    return {
      game_status_tbl = game_status_tbl,
      player_stat = player_stat
    }
  end
)
```



## 临时禁用 与 回调函数
根据地图的具体玩法, 可以临时不允许玩家存档.

可以设置回调函数, 在开始存档时触发

```lua
-- 禁用存档
ArchiveModule.allow_save(false)
ArchiveModule.set_save_data_callback(
  function()
    DialogModule.show_long_text_dialog(DialogModule.get_auto_dialog_id(), "存档功能被帝国敌军干扰了, 摧毁才能使用存档", {'确定'}, nil)
  end
)

-- 开启存档
ArchiveModule.allow_save(true)
ArchiveModule.set_save_data_callback(
  function()
    DialogModule.show_long_text_dialog(DialogModule.get_auto_dialog_id(), "正在存档", {'确定'}, nil)
  end
)
```



## 禁用存档功能
存档功能有一点点性能损耗, 如果地图仅用于联机, 可以禁掉存档功能. 该行为是不可逆的

```lua
ArchiveModule.disable_save_feature()
```



# 读取游戏数据
## 加载lua脚本
在正常情况下, 载入存档时, 所有lua函数和变量都没了, 所以需要在载入存档时, 重新运行那些用于初始化的lua脚本 (如声明函数, 设置配置等不会改变的值等)

只需要注册一下脚本名, lua库会自动导入运行

```lua
ArchiveModule.set_auto_load_lua_files(
  {'init.lua', 'config.lua'}
)
```



## 加载存档数据
需注意: 读取存档后, 所有自定义ui都没有了(如顶部按钮和单位上的按钮), 需要在加载存档时将它们显示出来

```lua
-- 假设有存放游戏状态的全局变量 game_status_tbl , player_stat

-- 先判断是否需要读取存档
if GameModule.get_frame_number() == ArchiveModule.get_last_load_data_frame_number() then
    local saved_data = ArchiveModule.fetch_and_clean_saved_data() -- 该函数只能能调用一次, 调用后存档的原始数据会被清理
    game_status_tbl = saved_data['game_status_tbl']
    player_stat = saved_data['player_stat']

    -- TODO: 重新执行显示ui的函数
end
```
