# 创建/打开/保存

> 原文：https://www.yuque.com/muzeqaq/ra3mapwiki/xwe89hd0xpvb8q31
> 目录位置：C#库

:::success
作者: dreamness

:::



# 创建地图
```csharp
// 新建一个ra3地图, 可游玩区域为200x300, 边缘宽度为10
// 实际地图尺寸为220x320
// 会自动创建2个玩家出生点
var ra3map = Ra3MapFacade.NewMap(200, 300, 10);

// 新建一个ra3地图, 不自动创建出生点
var ra3map = Ra3MapFacade.NewMap(200, 300, 10, 0);

// 新建一个ra3地图, 指定默认的纹理
var ra3map = Ra3MapFacade.NewMap(200, 300, 10, 2, "Grass_Geneva01");

```



# 打开地图
```csharp

var ra3map = Ra3MapFacade.Open(Ra3PathUtil.RA3MapFolder, "test_map");

```

# 保存/另存为
```csharp
// 保存, 替换原来打开的ra3地图文件
// 如果是创建新地图, 不能调用Save, 只能调用SaveAs
ra3map.Save()

// 另存为
ra3map.SaveAs(Ra3PathUtil.RA3MapFolder, "test_map");
```
