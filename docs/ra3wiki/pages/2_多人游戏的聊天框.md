# 2_多人游戏的聊天框

> 原文：https://www.yuque.com/muzeqaq/ra3mapwiki/rz2oftuit1n1m5i6

支持的功能

+ 在聊天框中输出文字
+ 监控玩家输入的文字



该例程展示了如何在聊天框中输出文字, 如何监控各个玩家的输入

注意, 只有当玩家的输入以 <font style="color:#DF2A3F;">/</font> 开头才能被识别, 且有字符长度限制



![](https://cdn.nlark.com/yuque/0/2024/gif/34558013/1734185380615-6c440179-214c-4656-883b-367c1c43243e.gif)



```lua

-- 注册监控函数, 用于获取用户输入的文字
ChatMsgModule.register_chat_listener(function(player_name, content)
    -- 在聊天框中输入文字
    ChatMsgModule.print_on_chat('player <' .. player_name .. '> said: ' .. content)
end)
```



该功能可以用于识别用户的各种指令, 发布公示信息等.
