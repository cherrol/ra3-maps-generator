# 欧拉角旋转


请ChatGPT老师解释一下

>  欧拉角（Euler Angles）是一组用于描述三维空间中刚体旋转的角度参数，通常用于计算物体在空间中的旋转状态。欧拉角定义了通过三个连续的旋转将参考坐标系变换为目标坐标系的方法。  
>
> + **偏航角（Yaw）**：绕 z 轴旋转的角度；
> + **俯仰角（Pitch）**：绕 y 轴旋转的角度；
> + **滚转角（Roll）**：绕 x 轴旋转的角度。
>

## Lua库实现
分别roll, pitch, yaw 30°

具体往哪个方向旋转? 使用**右手定则**

1. 拿出右手
2. 大拇指指向绕着旋转的**<font style="color:#DF2A3F;">轴的方向</font>**
3. 四指所指的方向, 即为旋转的方向

![](https://cdn.nlark.com/yuque/0/2025/png/34558013/1735752563911-495211dd-3790-4451-8c62-7a2781b2af81.png)

```lua
-- 注: 实际使用时, 三者可以任意组合

unit1:rotate_by_euler(30, 0, 0)
unit2:rotate_by_euler(0, 30, 0)
unit3:rotate_by_euler(0, 0, 30)

```

## (选看)实现原理
旋转使用了<font style="color:rgb(51, 51, 51);">‌</font>**<font style="color:rgb(51, 51, 51);">罗德里格旋转公式</font>**<font style="color:rgb(51, 51, 51);">, 该公式可以实现绕任意向量旋转</font>

<font style="color:rgb(51, 51, 51);">实现方法</font>

1. 获取单位自身坐标轴在全局的方向向量
2. 套用<font style="color:rgb(51, 51, 51);">‌</font>**<font style="color:rgb(51, 51, 51);">罗德里格旋转公式, </font>**让单位分别绕这3个方向向量进行旋转(旋转顺序为z->y->x)

```lua
    local hc = unit:get_homogeneous_coordinates()
    local x_dir_vec, y_dir_vec, z_dir_vec = HomogeneousCoordinatesUtil.get_axis_vecs_by_hc(hc)

    hc = MatrixUtil.dot(
        HomogeneousCoordinatesUtil.get_move_back_translation_matrix_by_hc(hc),
        HomogeneousCoordinatesUtil.get_rotation_matrix_by_vec(x_dir_vec, roll_angle),
        HomogeneousCoordinatesUtil.get_rotation_matrix_by_vec(y_dir_vec, pitch_angle),
        HomogeneousCoordinatesUtil.get_rotation_matrix_by_vec(z_dir_vec, yaw_angle),
        HomogeneousCoordinatesUtil.get_move_origin_translation_matrix_by_hc(hc),
        hc
    )

    unit:set_homogeneous_coordinates(hc)
```
