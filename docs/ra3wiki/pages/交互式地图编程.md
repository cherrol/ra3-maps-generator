本功能需要搭配Lua库使用

本功能可以实现在游戏运行中, 执行lua代码, 并且**<font style="color:#117CEE;">可以访问所有lua库和用户lua的变量和函数</font>**!

# 一 基本使用
:::color4
请确保, 在地图发布前, 移除该功能! 否则可能会有玩家作弊.

:::

首先, 在地图lua中引入该功能 

```lua
ChatLuaHelper.setup()
```

使用局域网功能进行游戏 (利用战网也可以)

![](https://cdn.nlark.com/yuque/0/2025/png/34558013/1740308061354-dd092fe1-9ec6-48d0-8236-42d47dc670bd.png)

在聊天框中输入代码, 即可执行, 代码需要以 "/" 开头. 每次不能超过35个字符. 如果想要输入超过35个字符, 请以"\"结尾, 代表下一行代码继续.

```lua
如, 想要输入以下代码
local u1 = UnitHelper.get_unit_from_id(14)
PublicBoardModule.show_text(tostring(u1:is_build_by_player(PlayerEnum.Player_1)), 10)

需要逐次在聊天框中输入:
/local u1 = UnitHelper.get_unit_fro\
/m_id(14) PublicBoardModule.show_te\
/xt(tostring(u1:is_build_by_player(\
/PlayerEnum.Player_1)), 10) 


```

_通过这种方法, 可以充分地利用代码补全功能_

:::success
一般来说, 该文件不需要导入地图中, 所以请在"Lua导入工具"中将该文件排除

直接逐行复制解析出来的代码即可运行.

# 三 高阶用法
## 1 尽量使用全局变量
尽量使用全局变量, 否则本次定义的变量, 下次执行无法访问

```lua
如:
第一次
local u1 = UnitHelper.get_unit_from_id(14)

第二次
u1:suffer_damage(100)

第二次会出错, 因为无法访问变量u1
如果某些变量想在后面公用, 请直接定义全局变量, 如 u1 = UnitHelper.get_unit_from_id(14)

```

## 2 忽略解析
某些代码不需要解析, 请以--[ 和 --] 包含起来

被注释的代码也不会被解析

```lua
--[
u1 = UnitHelper.get_unit_from_id(14)
--]
-- 让单位受到100点伤害
u1:suffer_damage(100)
-- 输出单位的生命值
PublicBoardModule.show_text(tostring(u1:get_health()), 10)
```

![](https://cdn.nlark.com/yuque/0/2025/png/34558013/1740309175284-bf32f500-0c53-4acc-a2e2-e171817ae3be.png)

## 3 拆分和注释
默认情况下, 所有的代码会被整合到一句代码

如果想要拆分, 请使用"--;"语法

```lua
--[
u1 = UnitHelper.get_unit_from_id(14)
--]
--; 让单位受到100点伤害
u1:suffer_damage(100)
--; 输出单位的生命值
PublicBoardModule.show_text(tostring(u1:get_health()), 10)
```
