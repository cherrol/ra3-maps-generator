# 宽高 / 边界
新建地图时, 会指定一些参数:

![](https://cdn.nlark.com/yuque/0/2025/png/34558013/1742490961931-d29584ac-ef3c-4b21-ad2b-9e080b3fe0ba.png)

这里的几个参数分别为:

+ playable width 可游玩区域宽度
+ playable height 可游玩区域高度
+ border 边界

地图实际的宽度和高度:

+ width = playable width + 2 * border
+ height = playable height + 2 * border

虽然新建地图的时候设定的是可游玩区域, 但在制图时, 需要考虑实际的宽高



# 两种坐标系
如建立了一个 可游玩区域200x300, 边界为20, 整体的宽高为240x340

### 大部分情况
将地图分割成240x340个正方形区域, 原点为左下角

如坐标(20, 30), 这里的x, y都是整形, 从0开始,

比如当前地图, x的取值范围是[0, 239], y的取值范围是[0, 339]

### 单位对象(object)和路径点(waypoint)
在此坐标系内, 将前者坐标系放大了10倍, 代表了地图中的具体某个位置, x.y可以为浮点型

原点(0,0)为可游玩区域的左下角

因此, 在本地图中, x的取值为[-200.0, 2200.0], y的取值为[-200.0, 3200.0]

![](https://cdn.nlark.com/yuque/0/2025/png/34558013/1742492045653-cf1de831-7c96-45d8-a301-d5fbde22d2fc.png)

具体取值, 可以参考地编中的坐标来理解
