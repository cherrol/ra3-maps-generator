# 6 纹理

> 原文：https://www.yuque.com/muzeqaq/ra3mapwiki/ziot9ih690o5fkeg
> 目录位置：Python库

:::success
作者: dreamness

:::

```python
m_2 = Ra3Map.load_map('m_2')

# 所有的纹理保存在TextureEnum里, 请按需寻找

# 设置一个区域的纹理
for x in range(70, 90):
    for y in range(20, 90):
        m_2.set_tile_texture(x, y, TextureEnum.BB_Pavement02)

# 获取一个位置的纹理
print(m_2.get_tile_texture(100, 150))

m_2.save()
```





若使用非官方纹理(如mod图引入), 需要先注册纹理

```lua
m_2.register_texture('texture_id', 'texture', 'bump_texture')
```
