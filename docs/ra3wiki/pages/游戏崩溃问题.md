# 已证实的地编内地图设置导致的游戏崩溃问题
## 队伍数量上限
在自制地图中，游戏内可存活的`每个玩家`的队伍数量上限约为 `**72**`** 个**。其中：

+ AI 玩家：由于作战策略的需求，“遭遇战AI” 会调用大约 32 个队伍的占用数。
    - 日冕 MOD 的 地狱AI 作战策略对队伍数量的需求更高，占用约40-50个队伍。
+ 地编设置：因此，如果AI玩家开启了遭遇战AI，那么可设置的可存活队伍（Team）数量最多为 20 个，在不考虑遭遇战AI的情况下(PVE中即地图AI全部通过猎杀操作单位)，数量可适当放宽。

**如果可存活的地编队伍数量超过上述限值，则可能会出现以下情况：**

+ 游戏在执行脚本时，队伍内存地址查询到非法地址，导致游戏发生闪退。

通过合并队伍，可以减少地编队伍的占用数量，从而避免队伍数量溢出，解决此类游戏闪退问题。

## 内存或显存超过上限
 RA3 是 32 位程序，系统内存上限为 4GB。在某些自定义地图中，玩家可能在高画质下遭遇崩溃，而低画质下则不会。这可能是由于高画质下内存消耗增加，超过了游戏的最大内存上限。  

另一个可能是玩家没有在日冕客户端内启动内存扩展，导致RA3只能使用2GB内存，大幅提高内存超限几率。



## 单行lua脚本超过32kb
目前版本地编(V17)的导入lua文件按钮可以导入大于32kb的lua代码文件，不会报错，但是实际进入地图时，这会导致游戏立即崩溃。

因此在写lua时，单个文件应当控制行数，尽量不要超过32kb（约1000行)。



## 带震动效果的物体过多
例如大量刷新质子撞击炮炮弹，会产生震动屏幕的效果。如果处理不当，会导致游戏崩溃。

本质上这是一个游戏bug，在日冕3.220中已修复

## 放置了中立维修峰作为美化
中立维修峰飞出地图边界太远导致崩溃。

# 游戏本身bug造成的崩溃
## 金甲技能冲锋时，偶发状态冲突导致游戏崩溃。
该bug极为罕见且难以复现，因此一直未能被修复。
