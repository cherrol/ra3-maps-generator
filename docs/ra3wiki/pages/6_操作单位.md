# 6_操作单位

> 原文：https://www.yuque.com/muzeqaq/ra3mapwiki/gb155s1bp02dmcze
> 目录位置：Lua库 (推荐使用)（先看安装使用流程！！）/代码样例

本库对单位Unit进行了封装, 封装的对象内包含单位的id, table, name, 以及可以直接进行一些针对单位的操作

可以通过**UnitHelper**, 通过id/name/unit_table快速获取一个unit

![](https://cdn.nlark.com/yuque/0/2024/png/34558013/1734757099974-04826a3d-307f-4836-ab77-42ea9ff1697e.png)



获得到unit后, 可以直接对这个单位进行操作

![](https://cdn.nlark.com/yuque/0/2024/png/34558013/1734757182940-a37c06a9-1470-491a-ac00-937ec7e934b7.png)



也可以方便地取出单位的id/name/table

```lua
local unit1 = UnitHelper.get_unit_from_id(10)
local id = unit1.id
local name = unit1.name
local unit_table = unit1.unit_table

-- 调取需要unit_table, id或name的函数时, 可以直接获取
ProductionQueueModule.get_queues(unit1.unit_table)
```



在调用其他函数, 需要传入unit相关信息时, 可以根据参数名和类型来判断应该传入什么

![](https://cdn.nlark.com/yuque/0/2024/png/34558013/1734757742761-bf72c854-a300-41b3-86e0-82e0e03302e9.png)

![](https://cdn.nlark.com/yuque/0/2024/png/34558013/1734757779636-e604f5c1-dcdf-4386-b222-631c793b084f.png)
