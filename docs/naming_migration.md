## 改动与保留

- 游戏目录、发布文件、`MAP_NAME`、欢迎文字、预览标题使用新名称；系列展示标题为“九州大地·地图名”。
- XML 的 DisplayName、Description、FileName 与 `map.str` 的显示名、简介、欢迎文字及版本提示同步更新，发布描述逐字采用命名文档。
- 全部 `.map` 二进制及小地图逐字节保持源版，因此高度、纹理、坡道、对象、脚本与玩法位图均未更改。XML 中 GameMap、纹理图集和脚本资产 ID 保持原样。
- `maps/` 目录、CLI id、地图专属规则模板及 `RULESET` 引用均采用新名，默认地图为碧嶂回澜。`RESOURCE_ID_SEED` 固定原资源命名空间，避免路径变化影响资源引用。历史源包、测试基线与版本记录不改写。

目录与 CLI 迁移没有修改已发布地图内容，因此不递增地图版本、不重新安装；四份发布 ZIP 和游戏文件的哈希保持不变。

现有 WorldBuilder 定稿可含边界外对象，纯命名迁移采用成品重封装的资源清单、纹理引用、脚本引用和 ZIP 回读校验，不重新执行生成图的对象边界限制。36 项 Rust 测试通过。每张新图 assets 中的 `rename-report.json` 记录二进制、资源身份及安装核对结果。附带的真实渲染图沿用源版画面，没有宣称新执行游戏实测。

## 归档与清理

先核对四份旧版备份，再生成新包、安装并逐字节校验，最后执行清理：

- `archive/九州大地/改名前/`：每图仅保留上表源版本一个旧发布版，包含原 ZIP、完整 assets、原配置与版本记录；`manifest.json` 记录 SHA256。
- `dist/` 和 `assets/`：四个旧名根目录已移除，当前版本位于四个新名根目录。
- 游戏 Maps：21 个本工程旧地图目录已删除，四张图各保留一个新名版本；其他地图不动。
- 测试夹具、参考输入和研究工作区不属于发布存档，不在此次清理范围。

本轮安装共 21 个成品文件，ZIP、assets、dist、游戏目录逐字节一致。迁移源包与新包中的 `.map` SHA256 相同。可复核的执行记录位于 `work/rename-release/`，包含源版本清单、清理计划及完成记录；归档清单位于 `archive/九州大地/改名前/manifest.json`。
