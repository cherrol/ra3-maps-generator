# 九州大地地图系列命名与发布描述

2026-10-27 用户确认采用本套命名。后续系列规划、地图命名、文案与发布以本文为准。

## 命名约定

- 合集名：**九州大地**。
- 单图采用四字山河意象名，通过地貌、风雪、云雾和潮汐区分各图。
- 单图名称不使用现实地名、省份简称、著名古地名或名山大川名称。
- 系列展示格式：`九州大地·千壑横原`；保留作者标识的游戏地图名称格式：`[CHAI]千壑横原`。
- 下表的地形原型仅供内部素材对应和开发核对，不作为对外地图名称或标题的一部分。
