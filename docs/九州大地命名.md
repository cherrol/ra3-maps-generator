# 九州大地地图系列命名与发布描述

2026-10-27 用户确认采用本套命名。后续系列规划、地图命名、文案与发布以本文为准。

## 命名约定

- 合集名：**九州大地**。
- 单图采用四字山河意象名，通过地貌、风雪、云雾和潮汐区分各图。
- 单图名称不使用现实地名、省份简称、著名古地名或名山大川名称。
- 系列展示格式：`九州大地·千壑横原`；保留作者标识的游戏地图名称格式：`[CHAI]千壑横原`。
- 本地 `maps/`、`assets/`、`dist/` 的外层目录按真实地形名组织，CLI id 使用同名；`assets/`、`dist/` 的成品目录保留生成发布名和版本；生成名用于预览标题、游戏地图文件和发布 ZIP 文件名。真实地形名不加入对外地图标题。
- 例如：`maps/陕西/`、`assets/陕西/[CHAI]千壑横原T0.7.8/`、`dist/陕西/[CHAI]千壑横原T0.7.8/`，发布包为 `dist/陕西/[CHAI]千壑横原T0.7.8.zip`。包内 `.map`、XML 显示名与游戏安装目录保持 `[CHAI]千壑横原T0.7.8`。
