## 本版修复与交付

原方形检查发现的11处赠送资源净距缺口，在完整EA地基、碰撞与真实出口扫掠口径下确认为14处，已全部修复。另显式重选P1机场主备2处，共16个航点及16处运行时检查区同步移动；XML、同版布局和冻结原生同步。48矿、21坡、出生组及脚本身份／条件保持，8条主次通路长度保持不变，全部最终净宽至少10格。

独立复核闭环110主备站、280创建分支、496资源接入关系、128实际产能分支及其完整本体阻挡后的外侧接入、两湖356段完整岸线回台地链。R15–R21的13段已确认材质硬接缝补齐普通混合，968格引用及290条新增描述之外的数据保持；有限自然第三材质端部逐点保留并复核。真实归档纹理的离线合成方法、静态模型及适用限制已明示，不当作游戏或地编实机渲染。

[13项独立验收](../maps/河南/histories/T0.1.1/acceptance.md)绑定最终候选文件、布局、参数和当前规则；747成员自包含证据归档保留原始测量、有限候选比较、保护对照及实际材质证据。已发布、采用完整新源，并完成不递增版本的全流程构建；[5个游戏文件及冻结复构证明](../maps/河南/histories/T0.1.1/package-verification.json)确认assets、dist、ZIP和source逐字节相同。执行范围与结果见[本版测试记录](../maps/河南/histories/T0.1.1/test-verification.json)。未安装或启动游戏。

## 公共流程与规范入口

规则以[公共约束总表](map_rules.md)及各专题为准，五份地图技能按[专业交接](map_skills_checklist.md)路由，判定统一见[公共验收](map_acceptance.md)。全部有效斜坡和完整引道优先于矿；自动零冲突不能代替这项设计判断。地形交接按[统一规范](terrain_transitions.md)核对实际几何、导航、材质及外观，AXAI／NKL／SMAI原生参考证据继续归档。

本次共性改进已进入共享实现和流程：[完整实际几何与小数坐标验收、默认局部修复与显式基地重选、最终实际布局传递、整组路线比较、生产本体外侧接入及完整岸线叠加检查](production_placement_fix.md)。局部材质修复使用已审精确格边选择组件，不自动重做同坡肩内其他界面。发布、安装和采用源继续要求与实际候选绑定的独立记录，失败保留待审候选；旧记录不自动覆盖新规则。其他33图目前没有赠送脚本可实测，不能将公共缺口直接当作这些图的现有缺陷，完整归因见[流程改进记录](../maps/河南/histories/T0.1.1/process-improvements.md)。

当前制作输入保存在[authoring](../maps/河南/authoring/README.md)：完整source.zip、布局、空间基准、对象身份及资源／赠送计划。147份与T0.1.0归档逐字节相同的旧报告已移出当前输入目录，审核状态只在本版histories维护，避免旧通过记录冒充当前状态。

## 输入与能力边界

首次检出按[可复现构建](reproducible_builds.md)从当前source.zip恢复文件。河南LAYERS仍引用histories/v3/layers.npz，根layers.npz为选定蓝图原字节镜像；当前版本以version.json为准，冻结来源以config.json引用的包、CRC和布局为准。

新图仍需建立自己的配方、出生组、路线、资源和脚本。当前局部二材修补不等于全图多材交汇或全周岸坡自动修复；新图独立spatial审计等剩余边界见[待办](TODO.md)。本地Linux测试不等于Windows CI运行结果。
