# 地形、坡道与纹理

按[公共约束总表](../../../docs/map_rules.md)选择本轮规范与来源。新图读取声明式蓝图和显式布局；冻结成品以完整原生高度、材质、位图及脚本为准，沿用本图配置引用，不从旧蓝图重挖。

## 坐标与设计范围

位置统一通过本图 `coordinates::Frame` 换算。宽高、边框、格长和高度比例读取本图声明；原生数据、内部北向和图片储存行序按[坐标规范](../../../docs/map_coordinates.md)处理，不根据水域方位猜轴向。

公共设计预览按[预览标准](../../../docs/terrain_preview.md)确定正方形网格、完整地理取景、真实分层和水域。预览设计帧与已有可玩 Frame 分开，PNG 图例不计入地形格数。真实高程和来源岸线留档，设计水域与原始轮廓分别记录。

## 交战路线与伸入地形

按[交战路线与伸入地形整理](../../../docs/terrain_preview.md#交战路线与伸入地形整理)读取公共 `terrain_shape` 参数，分别检查层、陆地和水域：交战通路净宽不足时适当拓宽补足，细长伸入部分不足其门槛时并入附近实际相邻区域；两类重叠仍须保证交战路线要求及连续连接。保存范围、逐段净宽、目标选择和前后数组，联动导航、资源、岸线及参考输入；仅改图片或策略不算落实。

全部赠送建筑主备及条件分支的完整占地、出入口和接驳预留均避开伸入区域，宽度达标也不得放置。按[独立验收](../../../docs/map_acceptance.md#交战路线宽度与伸入地形如何验)提交宽度、拓宽／归并及赠送排除三项同版证据；当前没有完整公共自动门禁。

## 坡道与全周岸线

按[小水域单层包裹规则](../../../docs/terrain_preview.md#小水域的单层包裹)处理跨层小水域：先统计调整前各层的接岸长度，选接触最多的层，将全周岸边陆地统一划入该层，局部整理层界以完整包裹水域。保存接触统计、归属及前后分层证据，按[岸线验收](../../../docs/map_acceptance.md#整圈岸线如何验)逐处检查全周单层与后续水陆连接；仅填写策略或修改图片不算落实。

按布局定稿坡道位置、方向、连接层及宽度；坡形和表面遵守[山地斜坡规范](../../../docs/mountain_ramps.md)。斜坡数量不限，按[数量与通行布局](../../../docs/mountain_ramps.md#斜坡数量与通行布局)方便玩家通往交战区及矿、油井、医院等中立资源，按需增设或移动；按[通行便利验收](../../../docs/map_acceptance.md#交战区与资源通行便利如何验)核对实际路线、绕行和瓶颈，不能仅以可达或沿用旧坡数定稿。资源与建筑避让读取[公共坡口策略](../../../docs/ramp_clearance.md)，覆盖完整坡面、端口区及矿场占地，保护已确认基地、资源、通路和赠送主备点。

按[公共交付验收](../../../docs/map_acceptance.md#整圈岸线如何验)列全适用小岛、小水域和内外边界，逐段记录全周覆盖、过渡宽度、高度／坡度、阻挡、导航及双向跨层结果。不能只凭色块接触、中心可达或少数坡口通过；公共全周自动门禁尚不完整，缺逐段证据记待核验，不宣称完整通过。坡形、坡口或导航修改后，联动重验布矿通路和热点双方实际路程，结果汇入同版各项交付记录。

已有成品的坡形、坡口表面、移动／增设分别使用 `polish-ramps`、`polish-ramp-surfaces`、`relocate-ramps`，沿用最新完整 ZIP，按 ra3-pipeline 验收并冻结。

本轮涉及的建筑和矿脉选向遵守[公共四向规范](../../../docs/production_placement_fix.md#所有建筑的四向约束)，同项朝向验收不得漏查 `OreNode`。朝向变化后按[交付验收](../../../docs/map_acceptance.md#建筑朝向如何验)复验实际旋转占地、完整矿场规划矩形、矿口接驳、出入口与坡口；通行或占地变化还须联动岸线和热点路线，不能靠任意角度挤出空间。

## 材质与封装

选材与纹理后处理按[公共纹理规范](../../../docs/terrain_texture_rules.md)，清理与硬上限按其中的“公共纹理清理与数量上限”。原生表、两份加载清单和 XML 图集成套更新；清理不改变实际绘制、子贴片相位或玩法数据。已有成品纹理更新用 `polish-textures`；纯封装修复用 `repair-terrain-package`，不删除资源声明规避错误。

来源衔接、所选蓝图镜像和版本留档统一按[版本资料](../../../docs/blueprint_versions.md)与 ra3-pipeline。生产流程不包含实机检查。
