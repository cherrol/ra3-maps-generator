# 地形、坡道与纹理

先按[公共约束总表](../../../docs/map_rules.md)选择本轮范围。新图读 `LAYERS` 与显式 `LAYOUT`；成品编辑读 `COORDINATE_PIPELINE` 引用的完整原生 ZIP、CRC 与布局，保留本轮无关的高度、材质、位图、身份与脚本，不从旧蓝图重挖。两条路径均执行当前严格规则。

位置通过本图 `coordinates::Frame` 换算，宽高、边框、格长及高度比例查[坐标规范](../../../docs/map_coordinates.md)，不按 PNG 像素或水域方位猜轴向。预览按[公共预览](../../../docs/terrain_preview.md)使用独立设计帧，保留真实高程和来源岸线；设计结果与原始资料分开记录。

## 先主路与坡口，再矿位

按[坡口布局](../../../docs/mountain_ramps.md#沿路线选坡位与按层界定朝向)以对位双方实际基地连线为大致方向：先保障直接主路，再定跨层坡口、低高端口及完整引道，最后安排矿位。侧翼仅作补充；允许合理地形转折，不为保矿改走远坡或强迫主路绕远。坡轴仍按真实低高层界和端口接入确定，不强转对手向量，也不新增角度或绕行比例阈值。

按[斜坡优先级与冲突处理](../../../docs/ramp_clearance.md#斜坡优先级与冲突处理)，所有有效坡道的全宽坡体、端口及完整上下引道优先于矿。将保护范围交给 ra3-resources 退让矿盘、旋转矿场和接驳，不为保矿削改、缩窄或挪动合理坡道；新增合理坡位候选碰矿也先联动移矿，不由旧矿坐标或局部工具占地锁直接否决。确因地形／通行整改改坡时记录真实原因及前后差异；无联合可行解按验收记失败或待核验。开局两矿调整由 ra3-spawns 复验[完整出生组](../../../docs/spawn_placement.md)，本轮范围外对象继续保护。

斜坡数量不限，按交战区及全部中立资源接入需要增设或移动，不固定任何地图的配对、坐标或坡数。已有成品沿用最新完整 ZIP：坡形用 `polish-ramps`，坡面材质用 `polish-ramp-surfaces`，移动／增设用 `relocate-ramps`；后续构建与冻结由 ra3-pipeline 衔接，普通重包不会应用地形修复。

## 形状、水陆与朝向

- 按[地形交接规范](../../../docs/terrain_transitions.md)联合设计坡面、层界、岸线及其交汇处，先落实连续几何和预期通行，再接材质与混合。读取本图实际高度、水面、导航及上下地表，不套用参考系列样本数值；交汇处单独回读，避免各段独立修补后留下尖角、断坎或材质接缝。
- 按[交战路线与伸入地形整理](../../../docs/terrain_preview.md#交战路线与伸入地形整理)及公共 `terrain_shape` 参数处理层、陆地和水域：不足通路拓宽，不足细长伸入就近归并并保持连续接入。全部赠送主备／条件分支的完整占地、出口与接驳避开伸入区域，宽度达标仍禁放。
- 按[小水域单层包裹](../../../docs/terrain_preview.md#小水域的单层包裹)，以调整前接岸长度最多的层统一全周岸边，再落实适用小岛、小水域的全周连续、双向水陆过渡。同步实际分层、导航与参考输入，不以中心可达、少数坡口或改图替代。
- 本轮涉及的建筑与全部矿脉 `OreNode` 遵守[公共四向](../../../docs/production_placement_fix.md#所有建筑的四向约束)，覆盖预置与脚本创建／转向。改变朝向后联动复验旋转占地、完整矿场、出入口及通路，不以任意角度挤出空间。

## 材质与交付

按[纹理规范](../../../docs/terrain_texture_rules.md)选材和清理，原生表、加载清单与 XML 图集成套更新，保留实际绘制及子贴片相位。成品纹理更新用 `polish-textures`，纯封装修复用 `repair-terrain-package`，不删除声明规避错误。

按[公共地图交付验收](../../../docs/map_acceptance.md)提交实际坡形／坡口、主路与资源通行、叠加完整赠送预留后的净宽、伸入整理、全周岸线及纹理封装证据。[斜坡优先级验收](../../../docs/map_acceptance.md#斜坡优先级如何验)覆盖全部有效坡道及冲突处理记录；将专业结果交给 ra3-pipeline 汇总，热点双方路程由 ra3-resources 联动复验。

[地形交接验收](../../../docs/map_acceptance.md#地形交接如何验)另核对几何、材质、导航和视觉是否对应，覆盖端口、坡肩、岸角及交汇处，复用上述同版证据。当前没有完整公共自动门禁；纹理封装或坡口零问题不代替连续衔接判断，缺少相应证据保留待核验。
