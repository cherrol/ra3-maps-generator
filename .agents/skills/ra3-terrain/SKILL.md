# 地形、坡道与纹理

先按[公共约束总表](../../../docs/spec/map_rules.md)区分预览设计与可玩制作，遵守[边界保护与斜坡添加](../../../docs/spec/preview_terrain_lock.md)。**可玩制作不得修改层边界与水陆边界，允许添加斜坡。** 新增斜坡可包含必要的局部坡面高度及通行变化；层边界按同版设计分层标签／掩码确定，不以合法斜坡的局部高度变化判为边界变化。只改流程时不检查或改动已完成的地图。

位置通过本图 `coordinates::Frame` 换算，宽高、边框、格长及高度比例查[坐标规范](../../../docs/spec/map_coordinates.md)，不按 PNG 像素或水域方位猜轴向。预览按[公共预览](../../../docs/spec/terrain_preview.md)使用独立设计帧，保留真实高程和来源岸线；设计结果与原始资料分开记录。

## 游戏预览阶段

预览制作中按[公共预览](../../../docs/spec/terrain_preview.md)设计分层、水域、路线宽度、伸入归并及小水域归层，定稿层边界与水陆边界，按[地形交接规范](../../../docs/spec/terrain_transitions.md)设计坡面、层界、岸坡及交汇处。坡位、高度、海深、平台和连接关系随同版设计数据交接；参考样本不覆盖本图设计。

## 可玩制作阶段

新图忠实转换选定预览及同版 `LAYERS`，读取显式 `LAYOUT`；已有成品读取 `COORDINATE_PIPELINE` 的完整原生 ZIP、CRC 与布局，保留层边界、水陆边界、未涉及新增斜坡的地形及对象／脚本身份。来源与选定预览的边界冲突时停止相关制作并记录差异，不覆盖任一方。

按[坡道规范](../../../docs/spec/mountain_ramps.md)识别既定坡体、端口、层界和完整引道，必要时在固定边界内添加斜坡；明确新增坡体、端口及完整引道，记录局部高度、导航和连接变化，将全部保护范围交给 ra3-resources 和 ra3-spawns。按[斜坡优先级](../../../docs/spec/ramp_clearance.md#斜坡优先级与冲突处理)退让冲突矿位，不为保矿削改、缩窄或挪动合理坡道；添加斜坡不授权搬移或删改既有坡。

核对交战路线、伸入区域及岸线的既定范围，叠加全部资源及赠送主备／分支的完整占地、出口与接驳。可玩制作不通过拓宽、归并、归层等改变层边界或水陆边界；缺少坡面细节时可在固定边界内补充斜坡设计，不以添加斜坡为名铺平平台。布局无解时保留失败／待确认，确需改边界则返回预览制作阶段，完成新预览及同版数据后重新交接。

本轮涉及的建筑与全部矿脉 `OreNode` 遵守[公共四向](../../../docs/spec/production_placement_fix.md#所有建筑的四向约束)，覆盖预置与脚本创建／转向。改变朝向后联动复验旋转占地、完整矿场、出入口及通路，不以任意角度挤出空间。

## 材质与交付

按[纹理规范](../../../docs/spec/terrain_texture_rules.md)选材和清理，原生表、加载清单与 XML 图集成套更新，保留实际绘制及子贴片相位。成品纹理更新用 `polish-textures`，纯封装修复用 `repair-terrain-package`，不删除声明规避错误。

材质整理不得夹带高度、水陆、坡形、通行／建造位图或连接关系变化；新增斜坡的几何与导航变化单独记录和验收。按[公共地图交付验收](../../../docs/spec/map_acceptance.md)提交层边界与水陆边界一致性、既有及新增坡口与引道、最终占地净宽、岸线及纹理封装证据；将结果交给 ra3-pipeline 汇总，热点双方路程由 ra3-resources 联动复验。

[地形交接验收](../../../docs/spec/map_acceptance.md#地形交接如何验)另核对几何、材质、导航和视觉是否对应，覆盖端口、坡肩、岸角及交汇处，复用上述同版证据。当前没有完整公共自动门禁；纹理封装或坡口零问题不代替连续衔接判断，缺少相应证据保留待核验。
