# 出生点与脚本落点

按[公共约束总表](../../../docs/spec/map_rules.md)确认本轮范围；地图 id 与展示名查[系列映射](../../../docs/spec/九州大地命名.md)。读取本图配置、布局、Frame、`BASES`、`RULESET` 及原生对象／脚本，按实际身份确定席位、玩家／固定 AI、阵营与外交，不按屏幕位置或对象顺序推断。已有成品使用本图完整原生来源，保护本轮范围外内容。

制作游戏地图遵守[边界保护与斜坡添加](../../../docs/spec/preview_terrain_lock.md)，保留选定预览或冻结源的层边界与水陆边界，在此范围内安排出生组及赠送；允许由 ra3-terrain 添加斜坡及必要的局部坡面高度、通行变化，层边界按设计分层标签／掩码核对。布局无解时记录冲突，确需改边界时返回预览制作阶段，不以添加斜坡为名铺平台或改岸。只改流程时不检查或改动已完成的地图。

## 规划与落点

1. 按[出生点规则](../../../docs/spec/spawn_placement.md)预选出生组，处理对置方位、角落／中间席位及两队水陆面积。每座基地与开局两矿须共享连续平层或水面的完整可用空间，容纳矿盘、矿场、接驳及通路；不能用中心同高或跨层可达代替同面，空间不足时重新选址，不压平其他层凑位置。
2. 联动 ra3-terrain 与 ra3-resources，按[路线与布矿顺序](../../../docs/spec/resource_distribution.md#对位进攻路线与沿路布矿)在固定边界内选取直接主路，保护既定跨层坡道及完整引道，必要时由地形技能添加斜坡。按[斜坡优先级](../../../docs/spec/ramp_clearance.md#斜坡优先级与冲突处理)由资源技能退让冲突矿位，本技能复验开局两矿的同面、近矿范围、配额与完整出生组，不为布局削改、缩窄或挪动合理坡道。
3. 通过本图 Frame 换算位置，同步 `base_cells`、原生出生航点、固定 AI 建造场、`dual-*` 产能点、模板超武／电厂点、赠送主备点及占用检查区。保留对象身份、归属、AI 判断与原触发条件，不因布局方向自动添加落座、分队、外交、现金显示或进攻脚本。出生点变化后由资源技能更新分级计划及配对双方到每座同一热点矿的实际同域路程，由地形技能复核通往交战区和全部中立资源的便利路线；接入不足先调整本轮布局，必要时联动添加斜坡，不能自行搬移或删改既有坡口。

## 赠送与朝向

按[布局优先级与统一选址](../../../docs/spec/production_placement_fix.md#布局优先级与统一选址)联合预留开局经济和产能出口；全部主点先于备用，产能主点先于其他赠送，同级优先处理地形受限者。使用实际归属基地与静态接入比较候选；本轮涉及的匿名装饰必要退让，具名、未知及范围外对象继续保护，并保留全部前后差异。

按[赠送建筑规则](../../../docs/spec/production_placement_fix.md)处理全部主点、备用点及条件／阵营分支：完整地基、出入口和接驳满足水陆、避让与占用重试要求；生产建筑优先靠近受益席位的实际基地，赠送建筑选取面向对方队伍中心的最近合法四向。已有成品按[受阻修复与重选](../../../docs/spec/production_placement_fix.md#已有成品的受阻修复与重选)区分局部 `repair-gifts` 和整体 `repair-production`；局部修复保留未受影响点，显式基地重选保留近点比较及理由，不整批采纳自动远迁候选。已确认主体范围纳入计划，仍与地形技能核对伸入排除，并与 ra3-pipeline 衔接发布。

按[伸入地形排除规则](../../../docs/spec/production_placement_fix.md#赠送建筑避开伸入地形)，提供全部主备／条件分支的完整赠送地基、出口及接驳预留，与 ra3-terrain 共同复核伸入禁放和叠加后的通路净宽。

按[地形交接规范](../../../docs/spec/terrain_transitions.md)把上述完整预留叠加到实际坡肩、层界、岸坡及交汇处，复验出生组同面、产能接入和双向过渡；颜色连续或岸边看似平坦不能代替原生高度、导航与占地核对。

初始基地、固定 AI 及其他预置／脚本控制建筑和全部矿脉 `OreNode` 均遵守[公共四向](../../../docs/spec/production_placement_fix.md#所有建筑的四向约束)。核对实际对象及创建／转向动作，不以航点角度代替；变更朝向后联动完整占地、矿口接驳、出入口及通路。

## 验收与交付

按[公共交付验收](../../../docs/spec/map_acceptance.md)提交出生组、座位／面积、全部赠送落点及靠近基地、朝向与脚本身份的同版证据；把完整赠送占地清单交给地形／资源技能复核关联通路。将专业结果交给 ra3-pipeline 完成原生回读、差异核对、版本与冻结源。
