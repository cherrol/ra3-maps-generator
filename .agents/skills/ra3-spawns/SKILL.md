# 出生点与脚本落点

按[公共约束总表](../../../docs/map_rules.md)确定新图、重布或冻结原样复现的规则边界。地图 id 与展示名查[系列映射](../../../docs/九州大地命名.md)；人数、固定 AI、阵营和外交读取本图 `BASES`、`RULESET` 及原生对象／脚本，不按屏幕方位或对象顺序推断归属。

## 出生组与队伍侧别

方位选择、水陆面积均衡及完整出生组由[公共出生点规则](../../../docs/spawn_placement.md)统一定义；本技能不维护方位列表或阈值。面积均衡尚未纳入公共自动门禁，须按规范独立计算、记录中线与逐类面积，不能用 `spawn_placement.passed` 代替。

先把每个出生点与开局两矿作为一组，在实际连续平层或水面共同选址，完整容纳基地可用空间、矿盘、矿场地基、接驳与通路。不得只验中心或用跨层可达代替同面；空间不足时在本轮授权范围内重新选择，不压平其他层凑落点。

位置通过本图 Frame 换算。新图同步 `base_cells` 与出生航点；冻结成品按完整来源和对象身份编辑，不用经纬度覆盖已确认落点。出生点重布联动[分级布矿计划](../../../docs/resource_distribution.md)，由 ra3-resources 落实本图主次路线及全部阶段；重新计算配对双方到每座热点矿的同域实际路程，不能沿用旧起点的距离。

出生点重布后按[通行便利验收](../../../docs/map_acceptance.md#交战区与资源通行便利如何验)重新核对各出生位通往交战区及矿、油井、医院等中立资源的实际路线；斜坡数量不限，需要时与 ra3-terrain 联动增设或移动，保持开局两矿同面及完整占地要求。

## 玩法与赠送点

出生点变更联动固定 AI 建造场、`dual-*` 产能点、模板超武／电厂点、赠送主备点及占用检查区。保持本图原触发条件、AI 判断、阵营与归属，不额外注入落座、分队、现金显示或进攻脚本。

赠送额外建筑按[伸入地形排除规则](../../../docs/production_placement_fix.md#赠送建筑避开伸入地形)避开伸入的层、陆地与水域；宽度达标仍禁放，全部主、备用点及条件／阵营分支的完整占地、出入口与接驳预留均不得重叠，仅检查航点中心不够。读取公共 `terrain_shape` 参数，出生点或赠送落点变化时联动交战通路不足拓宽、细长伸入不足归并及完整出生组，按[独立验收](../../../docs/map_acceptance.md#交战路线宽度与伸入地形如何验)提交同版证据。

赠送生产建筑按[所属基地选址原则](../../../docs/production_placement_fix.md#赠送生产建筑靠近所属基地)优先安排在受益席位基地周边；出生点、赠送归属或落点变化时，按[靠近基地验收](../../../docs/map_acceptance.md#赠送生产建筑靠近基地如何验)重查主备及全部分支，保留同版距离、接入及偏远落点的选择依据，不把旧航点搜索范围当作基地距离标准。

赠送完整占地、主备避让、占用重试和面向对方中心的朝向均读取[公共赠送规则](../../../docs/production_placement_fix.md)及其规则 JSON。找不到合格落点时报告冲突；已有成品修复用 `repair-production`，保留非本轮内容；该命令的现有自动结果不替代靠近基地的独立验收。

所有预置和脚本控制的建筑及矿脉只用[公共四向](../../../docs/production_placement_fix.md#所有建筑的四向约束)，覆盖初始基地、固定 AI、其他建筑、全部 `OreNode` 及主备／条件分支；赠送建筑继续选取朝向对方中心的最近合法方向。按[朝向验收](../../../docs/map_acceptance.md#建筑朝向如何验)回读实际对象和生成／转向动作，不以航点朝向代替对象角度；漏查矿脉不得记通过，旋转后重验完整占地、矿口接驳和出入口。

## 验收与衔接

读取 `spawn_placement` 的 `raw_passed`、`passed`、继承与新增／恶化项，区分零问题与本轮门禁通过。新图严格验收，重布组不能继承旧位置问题；完整资源、坡口和坐标验收由 ra3-pipeline 衔接，并按[公共交付验收](../../../docs/map_acceptance.md)提交布矿、坡口、整圈岸线、热点双方路程和建筑朝向的状态及同版证据；纯出生点修改可复用已证明未变的岸线测量，不能将未验项标为通过。冻结源与版本资料统一按[版本规范](../../../docs/blueprint_versions.md)，不以采用新基准掩盖失败。生产流程不包含实机检查。
