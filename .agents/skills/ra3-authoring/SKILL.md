# 从资料到地图

先按[公共约束总表](../../../docs/map_rules.md)确定本轮是纯预览、新图制作还是冻结成品修改。名称、目录与 CLI id 查[系列命名](../../../docs/九州大地命名.md)，不复制另一份映射或把生成名用作地图外层目录。

## 真实资料与预览

识别本轮高程、参考图片、轮廓和水域来源，按[公共预览标准](../../../docs/terrain_preview.md)准备内部输入。只有图片时按视觉蓝图解释地貌，不把目测分层称为测量高程；需要图像生成或编辑时使用 imagegen。地理取景、网格尺寸、分层、水域整理与中心标点要求均由该规范定义。

保留的小水域跨多个层时，按[单层包裹规则](../../../docs/terrain_preview.md#小水域的单层包裹)比较调整前各层接岸长度，将周边整圈陆地归入接触最多的层，再安排连续水陆过渡。预览交付前核对实际分层，留存接触统计、归属及前后证据；推进可玩制作时继续执行全周通行验收。

```sh
cargo run --release --locked -- terrain-preview <原型或图名> <高程NPZ>
cargo run --release --locked -- terrain-preview-centers <原型或图名>
```

按[交战路线与伸入地形整理](../../../docs/terrain_preview.md#交战路线与伸入地形整理)和公共 `terrain_shape` 参数核对层、陆地与水域：交战通路不足净宽时拓宽补足，细长伸入部分不足其门槛时就近归并，并为后续赠送建筑排除全部伸入区域。预览保存设计范围、净宽及前后数组；交战布局尚未确定时记录预留及待验范围，可玩定稿再按[独立验收](../../../docs/map_acceptance.md#交战路线宽度与伸入地形如何验)回读原生数据与全部赠送主备／分支，不能用预览结果代替实际通行及占地验收。

中心图需要有效地理范围和可靠的 WGS84 行政中心资料；工具不下载中心数据，不猜坐标。水域轮廓缺失时的低高程回退，不构成真实水域核对。主体边界外、游戏框内的真实地形也须处理。

交付 `maps/<id>/source.png`、`preview.png`、`preview--line.png`；已有有效中心数据时另输出 `preview--center--line.png`。参数、原始输入与设计帧放 `data/terrain-preview/`。纯预览完成即交付，不创建玩法布局、递增版本或安装。

## 推进可玩制作

新图按[配方](../../../docs/rust_migration.md)准备声明式蓝图与显式布局；预览缓存不能直接作为可玩 `LAYERS`。先建立本图 Frame，再确定地形／水域、坡道与完整通行预留，共同安排出生点和开局两矿，随后定稿扩张路线、其他资源、建筑和装饰。

斜坡数量不限，按[数量与通行布局](../../../docs/mountain_ramps.md#斜坡数量与通行布局)规划玩家通往交战区及矿、油井、医院等中立资源的方便路线，按需增设或移动坡口；定稿前独立完成[通行便利验收](../../../docs/map_acceptance.md#交战区与资源通行便利如何验)，不将历史坡数作为配额。

出生点用 ra3-spawns，资源用 ra3-resources，地形与纹理用 ra3-terrain，构建与冻结源用 ra3-pipeline。使用[出生点规范](../../../docs/spawn_placement.md)与[分级布矿规范](../../../docs/resource_distribution.md)准备本图计划，不套用其他地图的落点或配对；定稿前按[公共交付验收](../../../docs/map_acceptance.md)汇总布矿、坡口、整圈岸线、热点双方实际路程和建筑朝向记录。规划时同步安排全周岸线过渡及热点双边可走路径；可玩交付逐项留同版测量证据，缺证据记待核验，不能以自动命令通过替代完整验收。纯预览仅核对岸线设计，不虚填玩法验收。

已有冻结成品使用配置引用的完整原生 ZIP、布局和基准，保护本轮范围外的地形、身份和脚本；不从旧预览重建覆盖定稿。蓝图原字节镜像、版本快照与采用来源统一按[版本资料](../../../docs/blueprint_versions.md)执行。生产流程不包含启动游戏或 GUI 检查。

所有地图控制的建筑和矿脉 `OreNode` 从布局阶段即遵守[公共四向朝向规范](../../../docs/production_placement_fix.md#所有建筑的四向约束)，涵盖预置、中立、固定 AI 及脚本控制对象，不局限于赠送建筑。定稿前回读全部建筑、矿脉及其创建／转向动作，按[建筑朝向验收](../../../docs/map_acceptance.md#建筑朝向如何验)提交同版清单；漏查矿脉不得记通过，旋转后联动复验占地与通路。
