# 从资料到预览与可玩地图

先按[公共约束总表](../../../docs/spec/map_rules.md)确定本轮是纯预览、新图还是完整原生源编辑；目录、CLI id 与游戏展示名查[系列命名](../../../docs/spec/九州大地命名.md)。只处理本轮范围，完整来源不豁免当前严格规则。

遵守[边界保护与斜坡添加](../../../docs/spec/preview_terrain_lock.md)：预览阶段可设计地形边界；可玩制作保留选定预览或冻结源的层边界与水陆边界，允许添加斜坡及必要的局部坡面高度、通行变化。层边界按同版设计分层标签／掩码确定，不以合法斜坡的局部高度变化判为边界变化。确需改边界时返回预览阶段，完成新预览及同版数据后重新交接。只改流程时不检查或改动已完成的地图。

## 纯地形预览

识别高程、图片、轮廓与水域来源，按[公共预览流程](../../../docs/spec/terrain_preview.md)准备输入。仅有图片时按视觉蓝图判读，不把目测当测量高程；需要生成或编辑位图时使用 imagegen。处理整个游戏矩形，包含主体边界外的真实地形；设计 Frame 与可玩 Frame 分开，PNG 图例不计入地形格数。

设计中落实[小水域单层包裹](../../../docs/spec/terrain_preview.md#小水域的单层包裹)、全周水陆过渡，以及[交战路线与伸入地形整理](../../../docs/spec/terrain_preview.md#交战路线与伸入地形整理)：跨层小水域按调整前最多接岸层归并岸边，通路不足拓宽、细长伸入不足就近归并，全部赠送占地避开伸入区域。同步实际数组和参考输入，不能只改图或策略；交战布局未定时记录预留与待验范围。

按[地形交接规范](../../../docs/spec/terrain_transitions.md)同时预留坡面、层界、岸线及其交汇处的连续过渡空间，记录可通行与阻断边界。参考系列样本用于比较衔接做法，不能直接套用其高度、宽度、材质或局部断岸；纯预览只交付设计预检，实际几何、材质与导航留待可玩制作回读。

```sh
cargo run --release --locked -- terrain-preview <原型或图名> <高程NPZ>
cargo run --release --locked -- terrain-preview-centers <原型或图名>
```

交付 `maps/<id>/source.png`、`preview.png`、`preview--line.png`；有可靠 WGS84 中心资料及地理范围时另出 `preview--center--line.png`，不猜中心坐标。原始资料、参数与设计帧放本图 `data/terrain-preview/`。纯预览到此交付，不创建玩法布局、递增版本或打包安装。

## 推进可玩制作

按[Rust 配方](../../../docs/spec/rust_migration.md)准备 `LAYERS` 与显式 `LAYOUT`；预览缓存须忠实转换成构建输入，保留选定预览的层边界、水陆边界及未涉及新增斜坡的设计数据，新增斜坡及其局部变化单独记录，不能借格式转换重做边界。已有成品读取 `COORDINATE_PIPELINE` 引用的完整 ZIP、CRC 与布局，保留本轮无关的原生地形、身份及脚本；来源与选定预览的边界冲突时先列出差异，不自行覆盖任一方。位置统一通过本图[Frame](../../../docs/spec/map_coordinates.md)换算。

按[路线与布矿顺序](../../../docs/spec/resource_distribution.md#对位进攻路线与沿路布矿)在固定层边界与水陆边界内选择对位基地间的主路，识别既定跨层坡道，必要时由 ra3-terrain 添加斜坡并确定完整引道，再布矿。[斜坡优先于矿](../../../docs/spec/ramp_clearance.md#斜坡优先级与冲突处理)；冲突交给资源技能退让矿位，不为保矿削改、缩窄或挪动合理坡道。开局两矿移动后仍须满足[完整出生组](../../../docs/spec/spawn_placement.md)，外围矿沿实际主次路线分散。

将预览定稿数据忠实转换为构建输入，由 ra3-terrain 核对边界及新增斜坡与层界、岸线的交汇，出生／资源安排玩法占地，材质依附实际几何。缺少坡面细节时可在固定边界内补充斜坡设计；需要改变层边界或水陆边界的岸坡、平台等调整返回预览阶段，不以添加斜坡为名铺平平台或重塑边界。按[地形交接验收](../../../docs/spec/map_acceptance.md#地形交接如何验)保留同版剖面、导航及视觉证据。

出生组与固定 AI 用 ra3-spawns，资源计划用 ra3-resources，层界、岸线、坡道及纹理用 ra3-terrain，构建、版本与冻结源用 ra3-pipeline。布局阶段即执行[建筑四向规范](../../../docs/spec/production_placement_fix.md#所有建筑的四向约束)，覆盖全部预置、脚本控制建筑及矿脉 `OreNode`，朝向变化联动完整占地与通路。

## 交付衔接

证据、适用范围、状态与交付判定统一按[公共地图交付验收](../../../docs/spec/map_acceptance.md)。纯预览核对设计空间；可玩定稿将专业结果交给 ra3-pipeline 汇总原生回读、独立验收、版本与冻结源。
