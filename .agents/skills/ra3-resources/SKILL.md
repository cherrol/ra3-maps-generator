# 资源布局与完整占地

按[公共约束总表](../../../docs/map_rules.md)确定输入和本轮可修改范围。新图读配置 `LAYOUT`；冻结成品读 `COORDINATE_PIPELINE` 引用的完整来源及可编辑布局。坐标统一通过本图 Frame 换算，不按 PNG 像素或其他地图常数落点。

## 落点与阶段计划

先确定地形、水域和坡道，再将出生点与开局两矿共同选址，随后放扩张矿、油井、中立建筑和装饰。斜坡数量不限，按玩家通往交战区及矿、油井、医院等全部中立资源的需要与 ra3-terrain 联动布置；按[通行便利验收](../../../docs/map_acceptance.md#交战区与资源通行便利如何验)留存各目标实际路线及绕行／瓶颈结论，不以资源最终可达代替接入方便。出生组按[出生点规范](../../../docs/spawn_placement.md)检查连续平层／水面的完整空间，矿盘、矿场、接驳和相互通路一并核对。

新图与矿位／出生点重布必须按[公共分级布矿规范](../../../docs/resource_distribution.md)提交 `RESOURCE_DISTRIBUTION` 本图计划。阶段、配额、家区和主次线阈值从规范及其公共 JSON 读取；不照搬其他地图的坐标、路线或配对，不把仅满足近矿数当成整图分级通过。布矿和热点路程均按[公共交付验收](../../../docs/map_acceptance.md)逐项留证。对每座热点矿比较主线配对双方到同一目标的实际可走路程，记录原生 ID、同域路径、接入点、双方长度、差异及布置结论；运输需求、不可达或缺少长度不能记为通过，不用直线或主线采样进度替代。

新图同步分类清单、矿口角度与实际对象；冻结成品按原生身份派生清单，保留中立归属和非本轮对象。矿口方向同时核对内部角度、原生角度和翻 Y 后的实际朝向。

油井、中立科技、装饰性建筑、矿场及全部矿脉 `OreNode` 均纳入同一[公共四向](../../../docs/production_placement_fix.md#所有建筑的四向约束)验收，按[建筑朝向验收](../../../docs/map_acceptance.md#建筑朝向如何验)逐对象、逐创建／转向动作回读。矿脉与矿场的类型区别不构成跳过矿脉的理由；清单须与原生矿数一致，漏查或非法角度不得记通过。建筑或矿脉选向后重新核对旋转地基、完整矿场矩形、矿口接驳、坡口及通路，不靠任意角度挤出占地。

## 交战路线与伸入地形

按[整理规则](../../../docs/terrain_preview.md#交战路线与伸入地形整理)读取公共 `terrain_shape` 参数，与 ra3-terrain 联动拓宽不足的交战段、归并不足的细长伸入部分；调整后重验矿盘、矿场、资源接入及主次路线。全部赠送建筑主备／条件分支的完整占地与出入口须避开伸入层、陆地、水域，即使其宽度达标也不能摆放；按[独立验收](../../../docs/map_acceptance.md#交战路线宽度与伸入地形如何验)留净宽、前后范围与完整占地相交证据。

## 坡口与其他占地

按[公共坡口避让](../../../docs/ramp_clearance.md)读取生效策略，检查全宽坡面、声明端口和轴向两端通行区；矿按矿盘与旋转矿场矩形检查，油井和中立建筑按完整预留检查。赠送主备点也是需保护的占地，见[赠送规范](../../../docs/production_placement_fix.md)。

不得缩小公共占地、取消掩码或擅自移动既有资源来消除问题。冻结源旧问题只按来源身份继承，本轮新增／恶化必须处理；改变的落点不能继承原位置问题。未迁移分级计划的冻结图仅可在矿位与出生点不变时原样重建。

通过同版原生回读、分级计划、出生组、坡口及资源通路验收后，汇入布矿、坡口、整圈岸线、热点双方路程和建筑朝向的交付记录，再用 ra3-pipeline 定稿并采用完整来源。矿位、出生点、坡道或阻挡变化时，重验受影响路线和热点距离；缺少证据记待核验，不宣称完整通过。蓝图镜像与版本快照统一按[版本规范](../../../docs/blueprint_versions.md)执行；仅更新公共规则不自动重布现有地图。生产流程不包含实机检查。
