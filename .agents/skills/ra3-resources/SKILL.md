# 资源布局与完整占地

按[公共约束总表](../../../docs/map_rules.md)确认输入和本轮可修改范围。新图读取本图配置 `LAYOUT`；已有成品读取 `COORDINATE_PIPELINE` 引用的完整原生来源及可编辑布局。坐标统一通过本图 Frame 换算，按原生身份编辑并同步分类清单、矿口角度和实际对象，保留中立归属、脚本身份及本轮范围外内容；不套用其他地图的坐标、配对或 PNG 像素。

## 路线与分级落点

1. 与 ra3-spawns 预选完整出生组，再与 ra3-terrain 按[路线与布矿顺序](../../../docs/resource_distribution.md#对位进攻路线与沿路布矿)落实直接主路、跨层坡道及完整引道，最后安排矿位。按[斜坡优先级](../../../docs/ramp_clearance.md#斜坡优先级与冲突处理)保护所有有效坡道的全宽坡体、端口和完整上下引道；冲突先移矿，不为保矿削改、缩窄或挪动合理坡道，也不让主路绕远。地形技能提供真实层界、通路与保护范围，本技能据此退让矿盘、旋转矿场和接驳。
2. 所有可玩图均按[分级布矿规范](../../../docs/resource_distribution.md)提供完整 `RESOURCE_DISTRIBUTION` 本图计划。家区只留开局两矿，外围矿退出所有基地家区并沿实际主次路线分散。阶段、家区、配额与路线参数只读取该规范及公共 JSON；近矿数合格不代替完整分级布局。
3. 开局两矿可在本轮布局内小幅退让，仍须满足[出生点规则](../../../docs/spawn_placement.md)的近矿范围、两矿配额及与基地同处连续平层／水面的完整空间。矿盘、旋转矿场、矿口接驳与相互通路共同落实，不能缩小公共预留或取消掩码。矿位、出生点、坡口或阻挡变化后更新受影响路线，并比较主线配对双方到每座同一热点矿的实际同域可走路程。
4. 油井及中立建筑按各自完整占地落点；车库、医院、机场、精兵学院等按分级布矿规范分散在中间交战区附近，远离出生点。接入、分散与选址随本轮布局联动。

## 完整占地与朝向

与出生技能按[布局优先级](../../../docs/production_placement_fix.md#布局优先级与统一选址)共同预留开局矿场和生产主点／出口，再落实外围资源与其他主点、最后安排备用和装饰。矿数与分级继续完整满足；工具找不到联合可行位置时核对具体冲突并调整本轮相关输入，不擅自删除矿或全图重排。

已有成品发现赠送与矿场净距不足时，完整收集冲突及矿阶段，按[受阻修复与重选](../../../docs/production_placement_fix.md#已有成品的受阻修复与重选)比较局部移建筑、基地重选与必要移矿；不据首个错误推定仅一处，也不将缺少规划净距等同实际建筑重叠。移动赠送仍会改变资源通路，须按最终全部主备叠加复验。

按[坡口避让](../../../docs/ramp_clearance.md)读取生效策略，落实全宽坡面、声明端口和轴向双向引道；矿检查完整矿盘及旋转矿场，油井和中立建筑检查完整预留。与 ra3-spawns 核对全部赠送主备／条件及阵营分支的地基、出入口和接驳，按[赠送规则](../../../docs/production_placement_fix.md)保留必要空间并使生产建筑靠近所属基地。

涉及交战段或细长伸入地形时，由 ra3-terrain 按[地形整理规则](../../../docs/terrain_preview.md#交战路线与伸入地形整理)处理；本技能提交资源占地并复核接入，由 ra3-spawns 提供全部潜在赠送地基、出口及接驳预留，一并检查通路。

坡肩、崖脚、岸坡及交汇处使用 ra3-terrain 按[地形交接规范](../../../docs/terrain_transitions.md)提供的实际过渡范围，叠加完整资源占地并复验接入；不将视觉沙带或岩带当作平坦可建区，也不通过截断过渡来容纳矿场。

油井、中立科技、装饰性建筑、矿场及全部矿脉 `OreNode` 均遵守[公共四向](../../../docs/production_placement_fix.md#所有建筑的四向约束)，覆盖原生对象及脚本创建／转向动作。矿口同时核对内部角度、原生角度及翻 Y 后实际方向；变更后联动旋转占地、矿场接驳、坡口与通路。

## 验收与交付

按[公共交付验收](../../../docs/map_acceptance.md)提交分级计划、完整矿场／坡口避让、资源接入、热点双方路程和中立建筑选址证据。移矿后同步计划、分类清单、矿口朝向及原生对象，保留冲突与退让前后差异；不以分级或可达报告代替独立布局判断。将专业结果交给 ra3-pipeline 完成原生回读、差异核对、版本与冻结源。
