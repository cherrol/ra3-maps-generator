# 地形

# 获取基本数据
```csharp

var ra3map = Ra3MapFacade.Open(Ra3PathUtil.RA3MapFolder, "test_map");

var width = ra3map.MapWidth;
var height = ra3map.MapHeight;
var borderWidth = ra3map.MapBorderWidth;
var playableWidth = ra3map.MapPlayableWidth;
var playableHeight = ra3map.MapPlayableHeight;

Console.WriteLine($"地图信息 - 宽: {width}, 高: {height}, 边界宽: {borderWidth}, 可游玩宽: {playableWidth}, 可游玩高: {playableHeight}");


```



# 高度
```csharp
// 获取(10, 20)位置的高度
var h = ra3map.GetTerrainHeight(10, 20);


// 设置(30, 40)位置的高度为220
ra3map.SetTerrainHeight(30, 40, 220);
```



# 通行性
共有种通行性设置

上面两个最常用, 分别为 <font style="color:#DF2A3F;">可通行</font> 和 <font style="color:#DF2A3F;">不可通行</font>

+ Passable
+ Impassable
+ <font style="color:#585A5A;">ImpassableToPlayers</font>
+ <font style="color:#585A5A;">ImpassableToAirUnits</font>
+ <font style="color:#585A5A;">ExtraPassable</font>

```csharp

// 根据高度, 自动设置地图的通行性
// 建议设置高度后, 调用此函数, 避免发生单位直接爬悬崖的情况
ra3map.UpdatePassabilityMap();

// 获取坐标位置的通行性
var passability = ra3map.GetPassability(10, 20); 

// 设置坐标的通行性为"可通行"
ra3map.SetPassability(10, 20, "Passable");

// 设置坐标的通行性为"不可通行"
ra3map.SetPassability(10, 20, "Impassable");
```
