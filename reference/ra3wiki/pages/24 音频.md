# 24 音频

> 原文：https://www.yuque.com/muzeqaq/ra3mapwiki/vucxymsgake86bgs
> 目录位置：Lua库 (推荐使用)（先看安装使用流程！！）/代码样例

# 播放音乐
```lua
--; 播放音乐
AudioModule.play_music(MusicEnum.Corona_Celestial_March)

--; 停止音乐
AudioModule.stop_music()

--; 恢复动态音乐
AudioModule.resume_dynamic_music()
```

# 播放音效
```lua
--; 播放音效
AudioModule.play_sound(SoundEnum.Air_Definse_Warning1, nil, nil, nil)
--; 由单位播放音效
local u1 = UnitHelper.get_unit_from_name("u1")
AudioModule.play_sound(SoundEnum.Air_Definse_Warning1, u1.unit_table, nil, nil)
--; 由路径点播放音效
AudioModule.play_sound(SoundEnum.Air_Definse_Warning1, nil, "Player_1_Start", nil)
--; 由队伍播放音效
AudioModule.play_sound(SoundEnum.Air_Definse_Warning1, nil, nil, TeamModule.from_player_name("Player_1"))
```

# 播放EVA语音
```lua
--; 播放eva音效
AudioModule.play_eva_sound(EvaSoundEnum.Aeva_EstablishingB, nil, nil, nil)
```
