# 01_打印文字

> 原文：https://www.yuque.com/muzeqaq/ra3mapwiki/fi32elqqiwqeaid8

# ![](https://cdn.nlark.com/yuque/0/2025/png/34558013/1738643323267-33dddaec-b5e1-4f8c-a0f3-4970124e23da.png)
# 使用lua库
```lua
-- 设置公屏颜色为红色
PublicBoardModule.set_color(ColorEnum.RED)
-- 输出文字到公屏, 10s后隐藏
PublicBoardModule.show_text("Hello, World!", 10, nil)

-- 输出文字到聊天框
ChatMsgModule.print_on_chat("Hello, World!")
```

# 使用原生api
```lua
-- 设置公屏颜色为红色, 红色十六进制色号为#FF0000, 转为十进制即为77600000
exSetPublicBoardColor(77600000)
-- 输出文字到公屏, 10s后隐藏
exAddTextToPublicBoard('Hello, World!', 10)

-- 输出文字到聊天框
exMessageAppendToMessageArea('Hello, World!')
```
