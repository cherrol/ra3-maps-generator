# 启用/关闭监控玩家的鼠标位置
:::success
耗费性能的功能, 建议及时关闭

:::

```lua
-- 开启检测Player_1的鼠标位置
EventHelper.register_mouse_position_event(PlayerEnum.Player_1, 1)

-- 关闭检测Player_1的鼠标位置
EventHelper.register_mouse_position_event(PlayerEnum.Player_1, nil)
```



# 获取玩家的鼠标位置
如果获取不到, 会返回nil

## 获取鼠标在地图中的位置
```lua
local world_pos_x, world_pos_y, world_pos_z = MouseModule.get_mouse_world_pos(PlayerEnum.Player_1)
```

## 获取鼠标在窗口中的位置
:::success
注意, 该坐标原点在窗口的左上角

:::

```lua
local screen_pos_x, screen_pos_y = MouseModule.get_mouse_screen_pos(PlayerEnum.Player_1)
```
