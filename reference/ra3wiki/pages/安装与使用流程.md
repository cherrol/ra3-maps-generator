## 第一步 安装编程环境
### 安装vs code
[Download Visual Studio Code - Mac, Linux, Windows](https://code.visualstudio.com/Download)

### 安装EmmyLua插件
![](https://cdn.nlark.com/yuque/0/2024/png/34558013/1729390029454-6b21c896-be46-4616-b17c-a05d21172d68.png?x-oss-process=image%2Fformat%2Cwebp)

### (可选)安装TODO Highlight插件
![](https://cdn.nlark.com/yuque/0/2024/png/34558013/1734200791381-e05db1b2-a955-4264-b4fd-a7294d8b751f.png)

### 安装地编伴侣
[下载与更新渠道](https://www.yuque.com/muzeqaq/ra3mapwiki/vppua7qbrig4emxd)

## 第二步 下载并打开本lua库工程
新建一个文件夹, 如"ra3_map_workspace"

在地编伴侣的设置中, 配置lua库的安装路径, 并进行安装 (配置路径时, 指定刚刚新建的文件夹ra3_map_workspace)  
![](https://cdn.nlark.com/yuque/0/2025/png/34558013/1739245279990-224d8c1b-dc0b-4c5f-b933-368b8219fabd.png)



在该文件夹中, 新建文件夹workspace, 这个文件夹是你的lua工程的位置, 可以在该文件夹的子文件夹存储各个地图的lua文件

![](https://cdn.nlark.com/yuque/0/2024/png/34558013/1734860521435-567d7ce3-0cb4-418a-83f5-d116cc4e4060.png)

![](https://cdn.nlark.com/yuque/0/2024/png/34558013/1734860567433-a8359964-7df2-4a31-9718-c35b382339f5.png)

## 第三步 编写脚本
在文件夹ra3_map_workspace中, 右键选择"通过Code"打开

在workspace中, 新建文件夹, 存储自己的地图lua

在这开发过程中, 代码应该都可以**自动补全**了

![](https://cdn.nlark.com/yuque/0/2024/png/34558013/1734860668752-e0fd7397-46d0-48dc-a08e-a0ec6ddaa409.png)

## 第四步 将lua脚本导入地图中
使用地编伴侣

第一个库配置 ra3_map_workspace\RA3CoronaMapLuaLib**<font style="color:#DF2A3F;">\lib</font>**

第二个配置地图的lua地址ra3_map_workspace\workspace\xxx

![](https://cdn.nlark.com/yuque/0/2024/png/34558013/1734860817146-f77b3314-08c3-437a-86f2-5b10cdd7fd23.png)
