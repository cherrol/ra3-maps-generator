# 创建/获取/删除
```csharp
// 新建队伍
var team = ra3map.AddTeam("team1", "Player_1");

// 获取所有队伍
List<TeamAsset> teamAssets = ra3map.GetTeams();


// 删除队伍
ra3map.Remove(team);
```

# 获取/修改详情
```csharp
var team = ra3map.AddTeam("team1", "Player_1");

team.Name = "team2";
```
