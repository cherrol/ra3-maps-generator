# 九州大地·沃野奔流 T0.1.2

800×800可玩格、三层台地、双湖；西侧P1–P4，东侧P5/P7/P8/P6。保留48矿、每家2座开局矿及21处坡口，P2近坡与坡脚接路继续使用。

本版只改地表材质，针对游戏内坡口与层界的细节：原判据只把单格 35 以上的落差当陡面，4–6 格的坡肩因此保留上层草地，实机表现为发亮的草色陡墙；沿陡面外缘另有 2–4 格宽的碎石／泥土带，在斜向层界上连成阶梯状土条。现改为按实测坡度判定陡面（坡度 ≥8 即岩面，含坡肩与坡口侧壁），坡脚土带收窄为 1 格，并让岸线 4 格内不落岩面。

共重绘 21,124 格。岩石由 11,583 增到 8,799 + 1,057（第四层岩），坡肩草色陡面补岩；Dirt_Yucatan06 6,808→603、Gravel_Yucatan01 6,438→648，沿崖宽土带与斜向阶梯土条基本消失。混合记录由 2,888 降到 2,604 条，材质边界 32,820→27,915，无混合硬缝 646→551（1.97%→1.97%）。

高度图、全部通行／建造等玩法位图、对象列表与脚本逐字节等于 T0.1.1（高度 crc32 3773833044、位图 706,440 字节 crc32 1593470479，26 个区块中仅 BlendTileData 变化），因此出生组、矿位、赠送落点、坡口、通路长度与净宽全部沿用 T0.1.1 的几何与验收结论：

| 对位 | 主路格数 | 次路格数 |
|---|---:|---:|
| P1↔P5 | 772 | 936 |
| P2↔P7 | 773 | 773 |
| P3↔P8 | 768 | 838 |
| P4↔P6 | 760 | 846 |

斜向层界仍是一格一格的栅格台阶，这是高度场本身的形状，不是本版材质问题；如要削弱台阶观感需要改高度，按规则要重新完整验收，本版没有做。
