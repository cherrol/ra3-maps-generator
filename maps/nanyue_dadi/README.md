# [CHAI]南粤大地

命名对照 `[CHAI]八桂大地`：八桂是广西，南粤是广东。

地势来自公开高程，按配方里的层高切开，再收成连片的大层。北为南岭，中南部是珠江三角洲和沿海丘陵，西南是雷州半岛，南边是南海。北朝上，海在下方。

八个出生点按地形预览上的红圈放置。西队四人自北向南，最南的一位在雷州半岛尖外的水上。东队两人在陆上，另外两位是南海里的固定 AI，并与东队结盟。每个出生点旁边有两处近矿和油井。外围的矿铺在陆地和南海上，大约每人 5 到 6 处。机场、车库和一部分油井也可以落在水上。层与层、水与陆靠自动斜坡连通，其余交界不可通行。地表按层各贴一张：一层纽约草地，二层拉什莫尔草地，三层冰岛土，四层阿姆斯特丹铺装。外海是深水底，贴岸一条浅滩。
