# 地形

层高、哪一层不可通行、以及有没有分层蓝图，都读当前地图的 `maps/<id>/config.py`。配方启用分层蓝图时，跳过噪声、山体和海陆雕刻，直接采用蓝图。`geo.make_mask()` 仍要跑。不可通行的高山层不要接斜坡。

## 通用层高

新图写 `HEIGHT_PRESET = 'standard'`。工具按这组处理，不要在共用代码里另写一套：

- 水域高度 0–130。贴岸一段保持 130，外海再落到 0。斜坡和水上基地用贴岸的 130。
- 一层 210、二层 280、三层 350、四层 420。
- 五层是一些山峰，高度 500–1000，不可通行，不接斜坡。

没写这个预设的图仍用自己的 `levels` 和 `sea_flat`，一层保持原来的高度。

## 轴向

内部帧第 0 行是北。`.map` 高度场用游戏帧（`flipud`）。游戏内北朝上，海在画面下方。

- 高度图里海在上半；预览和小地图里海在下半。
- TGA 自底向上，写出前把画布翻一次。
- 不要再翻 `Geo.to_cell`。反投影：`lon = lon0 + (x-ox)/sx`，`lat = lat1 - (y-oy)/sy`。

## 地形预览

真实高程预览走 `tools/relief_preview.py --map <id>`。步骤固定：按海拔切层，连片（宽度，再加面积），相邻层和三面凸出，陆地层界顺着地形轻轻挪，海岸贴回初始地形并按较小阈值并入，最后处理陆地层窄颈。格数、半径、近海海拔和边界图例在该图 `config.py` 的 `PREVIEW`。没写的项用工具缺省，那组缺省是广东预览调出来的：宽 30、面积 50×50、相邻 80×80、海岸 40×40（半径 32）、窄颈 20、保留框水域宽度 8。层高仍用该图的 `LAYER_M`。预览陆地只画配方里强度为 1 的边界，邻省不计入陆地。可玩区宽和高各自在 600 到 800 格，边框 20 格。取景包住这块陆地，边界四周留白并整条落在图内，画面宽高各自在 600 到 800，可以不是正方形。这只改预览画幅，不改配方里的 `GRID` 和取景框。`COAST_KEEP` 是经纬度框，每张图自己写。

配方写 `LAYER_RINGS` 时，按那份掩码改陆地的层：`layer2` 是二层，`layer3` 是三层，其余陆地回到一层。水域不动。没写的图不认手圈。配方写 `LAYER2_PATCH` 时，只把那份掩码里的陆地改成二层，圈外和水域不动。没写的图不认这种圈。

预览只留三张图，不写 v1、v2、v3 这类中间版本：

- `source.png`：真实高程地形
- `preview.png`：游戏高度层
- `preview--line.png`：同一张游戏分层，带省界

## 斜坡

层与层、层与水默认不可通行。连片、海岸和窄颈按上面的地形预览处理，层按并入结果保留。斜坡只开在实际相接的大连片交界上。

- 斜坡按交界至少 1 条。没写 `ramp_max_per_edge` 时最多 3 条。配方写了这个数，就按它封顶，尽量让不同位置的玩家能过层、能到资源。
- 上坡方向朝地图中心或资源。对不上时仍要留下斜坡，保证出生点能到资源和中心，不必绕大弯。
- 配方写 `ramp_marks` 时，划线附近已有的斜坡挪到线上，上坡方向跟线一致；附近没有就补一条。没写的图不认划线。
- 配方写 `landing_coasts` 时，圈内整段海岸可登陆：贴岸水面抬高到仍低于水面判定、接近陆地，这段岸边不再封死。没写的图仍只在斜坡开口上岸。
- 配方写 `ramp_layout = 'face'` 时：一条斜坡只连接相邻两层，不同时跨过第三层；坡与坡不要挨着；开口在层块凸出的位置时朝向凸出的那一侧；开口在层块左侧、边界大致南北向时，垂直边界，下坡朝第一层。没写这个开关的图仍按原来朝中心开口，隔层相接也可以留坡。
- 边长 20–40。不要为了把单格落差压到 2.5 把坡拉长。
- 位置由 `plan_auto_ramps` 生成，写入该图 `terrain.npz` 的 `ramp_json`。不要用手工矩形当开口位置。
- 车道用配方里的土路纹理。沿坡落差按部队能走来验收，端缝 ≤ 12，横向 ≤ 10，剖面单调。
- 斜坡以外的层界靠坡度封死。水陆交界的陆地格在斜坡占地之外标成不可通行。不要再用堤道另开岸。

## 纹理

山地分层用通用刷法：配方写 `LAYER_TEX_PRESET = 'mountain'`，不要另写 `LAYER_TEX`。工具按这张图自己的 `LAYER_M` 从低到高，每层只贴一张：

1. `Grass_NewYork01`
2. `Grass_MtRush04`
3. `Dirt_Iceland05`
4. `Pavement_Amsterdam05`

第五层及更高不另配。已经写了 `LAYER_TEX` 的图保持原样，不套这组。没开预设、也没写 `LAYER_TEX` 的图仍是原来的草地混合。`LAYER_TEX_STRICT` 打开后，每块 8×8 按块内多数层上色，缓坡不再被统一岩壁盖掉。沙滩、城市、海床色带和斜坡车道仍按各自配方，优先级高于层纹理。城市纹理用配方里的 `CITY_TEX`。`CITY_TEX_ROUND = True` 时按半径逐格刷成圆，不把整块 8×8 一起铺上。没开这个开关的图仍按块角判断。`CITY_CLUSTER = True` 时，地级市的圆相接算一片城市：单独一片是一口油井加一栋小房子，多座挨着则两栋小房子在两侧、两口油井在中间。没开这个开关的图仍是每座城市一口油井、一到两栋房子。
