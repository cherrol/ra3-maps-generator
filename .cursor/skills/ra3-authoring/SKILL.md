# 从预览到游戏地图

后续每张图按这个顺序做。层高、出生、矿和构建命令的细则分别在地形、出生点、矿、流水线四份技能里。这里只定顺序，以及什么时候可以往下走。

## 1. 配方

一张图一个目录 `maps/<id>/`，配方是 `config.py`。id 用参数或 `maps/.default`。不要改 `.default`，除非用户要求换默认图。

格子、层高、矿配额、水深都写在这张图的配方里。不要把另一张图的数抄进来。

## 2. 地形预览

```
python -X utf8 tools/relief_preview.py --map <id>
```

这一步只给人看地形：北朝上，海在画面下方。定层、岸、主区边界和取景。不放矿，不放出生建筑。

预览只留三张图，不写中间版本：

- `source.png`：真实高程地形
- `preview.png`：游戏高度层
- `preview--line.png`：同一张游戏分层，带边界

连片、海岸、窄颈和水域保留框写在该图的 `PREVIEW`、`COAST_KEEP`。层高用该图的 `LAYER_M`。可玩区宽和高各自在 600 到 800 格，边框 20 格，高度图边长是可玩边长加两边框。预览画幅用同一范围，可以不是正方形，不改配方里的 `GRID` 和取景框。邻区只补陆地，不画进边界。

等人确认这张预览，再做游戏地图。

## 3. 定稿后写下高度和出生格

分层蓝图存在并被配方启用时，它就是高度来源。不再用高程重新切层，也不重画岸线。

出生点以预览上标出的位置为准，写入 `TERRAIN['base_cells']`。`BASES` 的经纬度是这些格的反投影，顺序对齐。人类在前，固定 AI 在后，这样路径点编号和外交一致。构建时先落高度、斜坡和登陆岸，再把这些格落到地形上。

谁是人类、谁是固定 AI、谁在水上、同层跨度、固定 AI 和谁结盟，按出生点技能。两个固定 AI 的阵营和性格也按出生点技能：p7 苏联欧列格，p8 帝国晋三。已确认的层和出生格保持不动，除非这一轮用户明确要求改。

## 4. 可玩内容

预览确认之后，构建按这个顺序落点。后面的让开前面已经占住的格子。矿、矿口、中立资源的细则在矿技能。斜坡、登陆岸、纹理的细则在地形技能。

1. 高度层、水域
2. 斜坡、登陆岸
3. 出生点
4. 近矿
5. 近处油井
6. 外围矿
7. 城市油田、房子
8. 哨站、精兵学院
9. 车库、医院、机场
10. 船厂
11. 纹理
12. 装饰。层交界铺岩壁，水陆交界铺沙滩。树沿层界、岸边和空地放。园石只放在层界低的一侧。躲开出生点、矿、油井和其他建筑，也躲开斜坡车道。树和石头脚下的格子不可建造。

出生格仍写在配方的 `base_cells` 里，构建时在斜坡和登陆岸之后才落到地形上。

每张可玩图用同一套脚本，写在该图配方里：

- `NKL_SCRIPTS = 'nkl_blizzard_scripts.bin'`：脚本包在 `templates/`。把 NKL blizzard 的公共脚本接在模板公共列表后面。某张图的 `data/` 里若有同名文件，用那一份。
- `ALLOW_NAVY = True` 且 `REMOVE_NAVY_BAN = True`：删掉模板里的 Only Ground、Only Ground Fix，以及接入脚本里开局禁止船厂和舰船的条目。不留关闭的空壳。
- `FORCE_SEA_AI = True`：每个固定 AI 开局 180 秒买 T2，360 秒造科技中心，科技中心落地后再买 T3。时间照 AXAI。强制造船厂和空军只加在落在水上的固定 AI，陆地 AI 只升科技。
- 按出生位置分队：每张图都加，没有配方开关。p1–p4 一队，p5–p8 一队。大厅正好四人时，这四人算西队，落在 p5、p6 的送到空的 p1–p4。细则在出生点技能的外交一节。
- 电脑现金：每张图都加，没有配方开关。战场左侧只显示电脑身上的钱，人的位子不显示。说明是 AI1–AI8。
- 第二座产能：每张图都加，没有配方开关。动作 467 在出生点旁的路径点直接生成该建筑，不进建造队列，不扣钱，不看电力。可选位先确认不是人类，固定 AI 不看这一条。兵营等该阵营重工至少一座、并且兵营至少一座时再放一座；重工、机场、船厂在该建筑正好一座时放第二座。帝国把核心也算第一座，帝国没有单独的机场。
- 重复条目在组装时删掉，不写进配方。模板的默认外交和确认外交，以及 NKL 的结盟、第二座机场、第二座兵营、第二座船厂，每张图都删。固定 AI 的旧科技计时在 `FORCE_SEA_AI` 时删。NKL 的进攻波只在 `TEAM_ATK` 时删；没开对位的图仍用原来的进攻波。基地车、第一座产能、发钱和防守留下。
- 进攻对位：可选公共脚本，默认不列装。配方写 `TEAM_ATK = True` 才装。开局满 1 分钟不看出兵数量，强制让进攻队打对位出生点，并优先打对位玩家。之后每 2 分钟再看一次，人数达到 20 再下令，不够就把队伍交还 AI 并取消优先目标。新图不要写这个开关。
- 开矿拓展：可选公共脚本，默认不列装。配方写 `ORE_EXPAND = True` 才装。只处理基地近矿以外的陆地矿，分给最近的出生点。苏联在矿场摆放盘外生成勘查车并展开，盟军要已有一座矿场才在同一距离生成采矿车并展开，帝国在矿点上生成矿产核心并展开。矿场由电脑自己盖。新图不要写这个开关。
- 开场字幕只写「欢迎来到」加该图 `MAP_NAME`，再加「祝大家玩得开心。」不写人数、版本和地形说明。

船厂物体仍按矿技能：可玩水域达到 20% 才放 1 个。内陆图同样挂这套脚本，不另放船厂。脚本在组装时改。不改磁盘上的模板，不改脚本名字符串。海底高度写在该图的 `sea_flat`，水深要让船驶离船厂。水陆落差仍要让岸边登陆坡通过验收。

共用工具里的新行为用该图的配方开关包住。没开这个开关的图保持原样。按出生位置分队、左侧显示电脑现金、电脑第二座产能，以及删掉和它们重复的旧脚本，每张图组装时都有。进攻对位和开矿拓展留在可选公共脚本里，默认不列装。

## 5. 构建和交付

```
python -X utf8 tools/build_all.py --map <id> --bump --install
```

顺序是地形、连通、组装、校验、预览、验收、说明、打包。验收不过，构建失败，版本号滚回，不把这次的图交给玩家。

玩家打开的是带版本号的新目录。不覆盖已经安装的上一版，也不删游戏 Maps 目录里的其他地图。

## 6. 之后的修改

改配方，再按第 5 步重建。已经确认的层和出生格不动，除非用户这次明确要求改它们。
